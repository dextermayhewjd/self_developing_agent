# 01396 产业发现：第五、六节

报告日：2026-10-21。估值原型：成长渗透型。金额均为人民币，表中收入、利润单位为亿元；算力注明精度，PFLOPS不等于GPU卡数。

本阶段结论：服务收入已有规模，但2027年60–80亿元服务收入、8–10亿元经常性归母利润尚未获经营证据支持。既有合同、已交付容量和新增容量能否形成足额计费，是决定方向的变量；意向订单、Token调用量及设备销售增长不能替代它们。本节提供条件模型，不给目标价，不把业务税后利润直接写成上市公司归母利润。

#### 2. S曲线、增长来源和可触达市场

行业处于快速扩张与部署方式切换阶段，但尚不能给本公司填写一个可靠的“全国渗透率”。两组外部渗透观察是：受访智算云用户中85.8%采用外部服务加自建的混合架构；69.2%认为未来两年智算占其算力仍在50%以内。这说明已采用者仍有结构替换空间，不代表85.8%的全国企业都已用AI，两组也不是同一指标，不能相减。[IDC与信通院联合调研，2026-07-01，样本250家企业](https://www.idc.com/resource-center/blog/idcx%E4%BF%A1%E9%80%9A%E9%99%A2%E8%81%94%E5%90%88%E9%87%8D%E7%A3%85%EF%BC%9A%E5%8D%81%E5%A4%A7%E7%9C%9F%E7%9B%B8%E9%A2%A0%E8%A6%86%E8%AE%A4%E7%9F%A5%EF%BC%8C%E4%B8%AD%E5%9B%BD%E4%BC%81%E4%B8%9A/)

- **Beta**：AI基础设施需求和外部租用市场扩张，不能仅凭本票收入增速归因于竞争力。IDC给出的2025年AI IaaS规模为486.7亿元、同比+128%；该口径比服务器采购或广义AI产业市场更接近服务收入，但云厂商对终端收费与本公司向云厂商供资源仍可能属于上下游两次营业额，不能无条件计算真实份额。[同一IDC原文](https://www.idc.com/resource-center/blog/idcx%E4%BF%A1%E9%80%9A%E9%99%A2%E8%81%94%E5%90%88%E9%87%8D%E7%A3%85%EF%BC%9A%E5%8D%81%E5%A4%A7%E7%9C%9F%E7%9B%B8%E9%A2%A0%E8%A6%86%E8%AE%A4%E7%9F%A5%EF%BC%8C%E4%B8%AD%E5%9B%BD%E4%BC%81%E4%B8%9A/)
- **Alpha候选**：交付大集群、调度异构芯片、取得有价格和回款约束的长期合同。公司披露了规模，却未给同代芯片的实际利用率、单位Token成本、SLA赔偿率和续约价格；这些优势尚不能量化为份额或单位回报。
- **并表变化**：本期1,020.9%的集团收入增速主要比较“旧地产集团”与“加入AI业务的新集团”，不能切分成景气贡献与抢份额贡献。现有材料也不能量化新增服务订单中，多少替代别家、多少是客户新增需求。两者均留空。

市场口径交叉核对：信通院给2025年广义智能算力服务规模超过1,300亿元，其中企业级约800亿元、消费级约500亿元；本公司ToB集群服务不能覆盖整个消费盘子。中报自引“智算云1,876亿元”但未列研究出处及定义，不能据此把486.7亿元抬高到1,876亿元再乘份额。三者不取平均、不相加。[信通院《智能算力服务研究报告（2026年）》第28–29页](https://www.caict.ac.cn/kxyj/qwfb/ztbg/202604/P020260430517209165899.pdf)、[2026中报第6页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0921/2026092101606_c.pdf)

物理侧可交叉看全国供给：截至2026年7月底为245万PFLOPS（FP16）。但该数未在披露中明确与公司FP16“稠密”统一，且混有自建、运营商和不同芯片资源；本公司“已交付及运营”也未分自有、租入或代管。**不能将5万÷245万所得约2%写成确定市占率，更不能拿全国容量直接乘租价得到独立TAM**。行业自下而上货币化还缺可出租比例、型号折算、已收费利用率和实际价格；双口径互证未完成，本节改用公司实际容量约束收入。[国家数据局，2026-08-29](https://www.nda.gov.cn/sjj/swdt/mtsy/0829/20260829153449424083118_pc.html)

可触达市场折扣必须显式保留：本票够得着的是芯片、互联、电力、交付地域与客户准入相匹配的ToB资源需求；不能把超大云生态内不可获得的订单、全部自建算力和全球Token消费一并算入。下文30%–50%的可触达比例仅为压力参数，没有独立统计证明。

#### 4. 自建2027收入模型：行业校验与物理约束并列

所有产品线统一用两种形状，不为不同业务偷换公式：

`自上而下收入_j = 2025行业规模_j × (1+行业增速_j)^2 × 2027可触达比例_j × 公司在可触达市场份额_j`

`自下而上收入_j = 可交付数量_j × 当年计费/验收系数_j × 每单位年服务费或交付单价_j`

算力用PFLOPS、设备用台套、物业用面积/可租单元。设备销量、验收ASP、基建分产品数量与行业盘子均未取得，以下不硬填；这也意味着本表不能直接加总成集团收入。

自上而下只作量级检验。2025起点486.7亿元取IDC AI IaaS，未来30%–50%年增速是本研究主动降速假设，低于2025的128%：理由是高基数、单位价格折让及效率提升可能使Token量与收入脱钩。可触达比例30%/40%/50%、其内份额10%/13%/15%均为私有情景参数，不是已验证市占率；较高份额需要交付和客户转换支持。

| 服务市场参数／2027结果 | 保守 | 基准 | 乐观 |
|---|---:|---:|---:|
| 2025–2027行业收入年复合增速 | 30% | 40% | 50% |
| 2027行业规模 | 822.52 | 953.93 | 1,095.08 |
| 可触达比例／可触达行业规模 | 30%／246.76 | 40%／381.57 | 50%／547.54 |
| 公司在可触达市场份额 | 10% | 13% | 15% |
| 对应公司服务收入 | 24.68 | 49.60 | 82.13 |

自下而上定义为：`R = C × b × P`。C为年内可用于交付的名义服务容量，b为上电、验收、计费起始月份、合同覆盖及服务抵扣综合形成的全年计费系数。b不是GPU任务占用率：若合同按专属容量收固定费，不能在其上再乘一次芯片利用率；如实际按卡时计费，才须把可收款的卡时占比纳入b。P为不含设备一次性交付的同口径单位年服务收入。

| 产品线与参数／2027结果 | 保守 | 基准 | 乐观 |
|---|---:|---:|---:|
| 服务C：PFLOPS，FP16稠密 | 55,000 | 85,000 | 120,000 |
| 服务b：全年计费系数 | 60% | 80% | 85% |
| 服务P：万元／PFLOPS年 | 7.2 | 7.2 | 8.0 |
| **服务收入R** | **23.76** | **48.96** | **81.60** |
| 服务器集成交付：数量×验收系数×ASP | —— | —— | —— |
| 旧地产、物管、租金及中心运营：分项数量×兑现系数×单位收入 | —— | —— | —— |
| Token、灵织等第二曲线：外部付费数量×兑现系数×单价 | 不另加，未拆出 | 不另加，未拆出 | 不另加，未拆出 |
| 规划及海外等储备的可估值持续收入 | 0 | 0 | 0 |

以上均为条件场景。容量从最近披露超过5万的量级出发，保守仅小增，基准扩大至约1.7倍，乐观约2.4倍；尚无完整交付排期支持。7.2万元是把约8万元合同点值代理打九折，8万元是不打折，均非市场报价。b的60%/80%/85%为投运与可计费压力参数，公司未披露可验证实绩。上下两算结果接近仅是情景的一致性检查，**不是两套独立证据互证，更不能把假设接近当作预测准确**。模型目前承重仍在未公开的C、b、P。

直接反推疑惑1门槛，比大TAM更有用：

- P=8万元、b=80%时，60–80亿元年服务收入需要C约93,750–125,000PFLOPS，是最近超过5万披露量级的约1.9–2.5倍。
- 若P降至7.2万元且b=80%，需要C约104,167–138,889PFLOPS；宣布“十万卡”不能替代这项验证，不同卡型算力与有效产出不同。
- 若只按约200亿元的五年合同点值理解为年服务收入40亿元，则仍缺20–40亿元年服务；但该合同口径尚未核准，这只是缺口示意，不是已锁定的40亿元。
- 产能上限要同时通过设备到货、机房上电与冷却、网络组网、客户验收以及已落实融资五关。已签投资金额或地方规划不能当作C。

领先指标为“剔除硬件和未验收项目的月度可收款服务账单＋相应FP16稠密计费容量”，同时跟踪到款及抵扣。60–80亿元对应全年平均月账单5.00–6.67亿元，必须结合起始月份看能否覆盖2027全年，年末达到该run-rate仍不等于全年达标。该指标比集团营收或意向订单更早，也更能证伪本模型。目前未取得这套月度数据。

#### 3. 模式定性与财务因果链

**这是先投设备、再按合同交付与计费的重资金ToB算力项目模式。** 软件调度与长期服务能提高价值，但已有证据不足以证明轻资产平台的边际成本或近乎无限扩展能力。

1. **设备与服务混合 → 集团营收不能直接承担持续收入估值。** 硬件验收可一次增加营收，服务须逐期履约。以23.83亿元AI合计年化，再用服务利润率套算，会把未拆分的8.63亿元收入错误赋予持续性。
2. **先预付/备货 → 验收上电 → 折旧和利息先后落地 → 经营回款未必同步。** 6月底高性能服务器存货13.21740亿元，设备预付款4.56858亿元；这些既可能支持交付，也可能因型号、供货或客户验收发生滞留，不能全当已运营算力。贸易应收净额由3.83658增至7.81565亿元，集团经营现金流0.44187亿元，对比设备购置现金18.51568亿元，显示模式对外部资金有实质依赖；无法据集团表判断成熟算力项目自身亏现金。[2026中报第44–45、60–62页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0921/2026092101606_c.pdf)
3. **预付款条款 → 还要核实实收与可动用性。** 集团合同负债由8.60951亿元到8.62339亿元，混有地产且几乎不变；不足以证实AI新增意向220亿元已变成大量自由现金，也不能据余额不变就断言AI没有回款，期间结转和新收可能相抵。[2026中报第40–41页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0921/2026092101606_c.pdf)
4. **售后回租 → 提前获得资金，同时锁定本息与服务费质押。** 8月13日协议购价约16.87亿元、61–62个月租期、总付款约19.21亿元，服务费应收质押，且放款须满足条件；资产中约6.80亿元账面值涉及先前租赁安排。不能将6月、7月、8月公告金额机械相加当作新增设备或净融资到账，也不能以期满1元回购说设备成本为1元。这些条款支持约五年的资金久期，却不消除技术折耗和服务降价风险。[8月13日融资租赁公告第2–3页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0813/2026081301435_c.pdf)
5. **合同折扣＋设备更新 → 长期利润不能直线外推。** 旧通函已明确3–5年后服务器回购/更新需大量资本；会计政策机器设备3–10年，历史估值曾假设部分固定资产5或8年，均不是每一代GPU经济寿命的验证。长合同若缺技术换代、价格递减与SLA成本表，仍可能发生收入有、自由现金少的结果。[收购通函V-26至V-27、V-38页](https://www1.hkexnews.hk/listedco/listconews/sehk/2025/0930/2025093001193_c.pdf)、[2025年报第161页](https://www1.hkexnews.hk/listedco/listconews/sehk/2026/0427/2026042703289_c.pdf)

#### 4. 成长原型的排雷适配与比较口径

- 应收与设备存货扩大不自动判雷；要分别看纯服务应收天数、回款、设备库龄、验收延误和客户合同对应。混合集团应收/收入、地产加服务器存货周转均不足以直接判断。
- 研发费用率与研发资本化率未取得可计算分子，不能填零。收购得到的软件、客户关系等无形资产不能自动归为内部研发资本化；“自研量子湃”也不能替代费用与投入披露。股份支付、税惠与补助对最终归母的影响需另外核减，本节不预设其为零。
- 本地`data/01396/peer_financials_benchmark.json`中，2026H1首都在线云主机、优刻得云计算、青云云服务毛利率分别约15.32%、23.52%、-1.97%，研发费用率中位数约10.17%。这些是含不同通算/软件/公有云组合的观察样本，不能用15.32%中位数直接证明本票35.5%有永久优势；要对齐GPU服务环节、成本含折旧方式和客户组合。原始来源路径保存在该JSON的`source_json`及`pdf_adjustment_evidence`字段。本公司研发数据缺失，无法完成同口径研发比较。
- 下游应以同一2027年度的经常性归母盈利做前瞻PE三情景，并单列现金更新成本检验；本节未验证的业务利润不能直接当分母。当前PE、PB与单期并表增速都不提供成长便宜的证据；负利润不算PEG，未盈利同业PS/EV-Sales另组。板块倍数由对应阶段处理，本阶段只提交经营条件。

## 判断要点（bullet，含“不确定”项）

- **盈利承重在算力技术服务。** 它约占集团收入59.4%，估算贡献约92%的毛利；把AI全部93.1%的收入份额都当成同质持续服务，会明显高估盈利质量。
- **60–80亿元服务收入是新增容量与计费兑现命题。** 既有合同历史模型的2027服务收入约40.17亿元；当前容量、订单金额及单位服务费对应关系尚未审清，不能把370亿元意向订单当作收入保障。
- **本节条件基准为2027服务收入48.96亿元、业务税后利润约5.96亿元，未扣少数股东和旧业务等。** 它不是盈利预测；达到门槛需要更高有效计费容量或更优单位回报，且满足最终归母归属。
- **长约有价值，但技术、折扣、融资和回款仍承担风险。** 五年合同可降低空置，并未消除后期降价；约五年租赁还款及应收质押使服务回款成为必须监测的资产约束。
- **不确定：量价、权益归属与成熟项目现金尚未验证。** 已有资料既不足以肯定8–10亿元归母能实现，也不足以认定成熟算力项目不能造血；这一疑惑保持待定，不能因为TAM大或并表增速高就解除否决项。
