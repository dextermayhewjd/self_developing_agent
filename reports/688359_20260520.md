## 二、公司（Company）

### 2.1 定位 / 商业逻辑 / 行业地位

**定位**：表面工程技术的研究及新型环保表面工程专用化学品与专用设备的研发、生产和销售，是国内少数可为 PCB、新能源等领域客户提供专用化学品及专用设备整体解决方案的表面工程技术服务提供商。[H]

**商业逻辑**：
- 上游：硫酸铜、硫酸钯、硫酸镍、次磷酸钠等金属盐类及化工原料；
- 中游（公司位置）：配方型电子化学品 + 通用电镀化学品 + 配套专用设备；
- 下游：PCB 制造（印刷电路板）、五金卫浴、汽车零部件、电子通讯、新能源（光伏/锂电/储能）；
- 付费动因：客户需要高性能、高稳定性的表面处理化学配方来实现电路板金属化、防腐蚀、可焊性等功能。公司以"化学品 + 设备"一体化方案降低客户切换成本，并通过"包线"模式（按产出面积收费）锁定 PCB 客户用量。[M]

**行业地位**：公司在国内 PCB 电子化学品领域属于国产品牌中的技术领先者，拥有 96 项发明专利、100 项实用新型专利，多项技术（水平沉铜、化学镍金、脉冲电镀铜、填孔电镀）实现国产替代。但与安美特、罗门哈斯、麦德美乐思等国际巨头相比，公司在规模、品牌、全球服务网络上仍有较大差距。设备业务（尤其复合铜箔电镀设备）处于国内先发位置，已与嘉元科技签订 2.43 亿元合同。[M/L]

## 七、环境、价值链与竞争分析

### 7.1 环境（宏观 / 监管 / 供需）

- **监管 / 地缘**：公司产品涉及危险化学品生产（目录中列明"危险化学品生产"），受安全生产和环保监管约束。中美贸易摩擦对 PCB 出口导向型客户有间接影响。目前未见针对性的重大政策风险或利好。国内对新能源汽车、储能的政策支持间接利好复合铜箔设备业务。[H/M]
- **行业供需**：全球 PCB 产业向中国大陆转移趋势持续，但 2024–2025 年 PCB 行业经历去库存周期，下游需求疲软，影响公司化学品出货。复合铜箔作为锂电池新型集流体材料，仍处于产业化早期，主流电池厂尚未大规模采用，设备订单取决于下游客户技术路线选择和产能扩张节奏。[M]

### 7.2 上游 / 下游与成本传递

- **上游**：硫酸铜、硫酸钯、硫酸镍、次磷酸钠等金属盐类。原材料占主营业务成本比例较高，价格波动直接传导至毛利率。CY2025 前五大供应商采购额占年度采购总额 24.72%，集中度合理。钯等贵金属价格波动为主要成本风险。[M]
- **下游**：以 PCB 制造企业为核心（印刷电路板分行业收入占比 63%），其次为五金卫浴（15%）、电子元器件（8%）、电子通讯（6%）、汽车零部件（5%）、新能源（2%）。前五大客户销售额占年度销售总额 30.18%，客户集中度适中。关联方 GREAT CHIEFTAIN ENTERPRISE 贡献 6.30% 收入。健鼎科技（3044.TW）为台湾上市 PCB 厂商，属优质客户。整体客户结构尚可，无单一客户依赖。[H]
