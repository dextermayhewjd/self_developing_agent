# 估值原型标注表

> 按「现金流形态」切分，不按行业名切。判据：两家公司如果**估值方法、失效指标、
> 必比口径**三样都一样，就是同一个原型。钨矿/铜矿/油气共用一段；同属「有色金属」
> 的黄金（看储量重估）与铜（看冶炼加工费）必须分开。
>
> `必比口径` 是本表存在的理由——它被 `equity-thesis.mjs` 的板块基准 agent 直接读取
> 并据以派活，把「这一节该跟什么比」从模型的自由发挥变成配置。改这一行等于改行为。

## 1. 耗竭资源型

归属判据：主要资产有可枯竭的储量，产出为同质大宗商品，售价外生
主估值方法：P/NAV（以储量/资源 NPV 为基座）
失效指标：
  - 当期 PE——分母全看商品价假设，同一天可差 10 倍（03858 实测：93.8 / 46.0 / 8.2 三个值同日成立）
  - PB——矿按历史成本入账，分母基本是 IPO 募来的钱，不是矿的价值
必比口径：
  - 板块 P/NAV 中位数（在产 / 开发中分开取）
  - EV / 资源吨（含金属量口径）
  - EV / 单位年产能
  - C1 或 AISC 在全球成本曲线的分位
必做分析：供需平衡表、政策配额、再生供给响应曲线、储量寿命 vs 采矿权期限
排雷阈值变体：折耗政策、剥采比资本化、复垦拨备、投产爬坡期净现比可为负
典型悬空点：成本曲线位置与储量 NPV 往往只有公司委托的技术报告一个来源，属私有基准

## 2. 周期加工型

归属判据：买入大宗原料、加工后卖出大宗产品，利润 = 价差 × 产量，产能重、产品与原料价格双向外生，无储量耗竭问题（典型：钢铁、电解铝、化工、水泥、造纸）
主估值方法：穿越周期 P/B × 正常化 ROE，或中周期正常化盈利 × 中枢 PE（framework.md 已定：当期 PE 失效，必须在稿里写明「单 PE 在此误导」）
失效指标：
  - 当期 PE——底部盈利趋零则 PE 虚高、顶部盈利爆表则 PE 虚低，方向与真实贵贱相反
  - 单期毛利率与同比增速——价差是均值回归的，把周期位置误读成经营趋势
  - 当期 EV/EBITDA——EBITDA 剔除了 D&A 与利息，确实比净利润稳，但底部价差压到现金成本附近时它照样趋零甚至转负，倍数随之爆表；且它把重资产的维持性资本开支当作不存在，系统性偏袒折旧重的产能。只有换成中周期正常化 EBITDA 才可用
必比口径：
  - 板块 PB 中位数与近十年 PB 分位（本地 peers_curated.json 的 PB 中位数是「外部·可回溯」的首选来源）
  - 板块正常化 ROE 中位数（取同业跨越一整轮周期的 ROE 均值，年份区间要写明）
  - 吨钢 / 吨铝 / 吨水泥 EBITDA 与单位现金成本在行业成本曲线的分位
  - 板块产能利用率与社会库存天数中位数
  - EV / 单位产能（吨产能重置成本口径）
必做分析：价差（产品价 − 原料价）时间序列与当前分位、行业在建产能与政策去产能进度、能耗双控与碳成本约束、开工率与库存周期位置、单位现金成本相对行业分位、明确写出周期位置判定（底 / 中 / 顶）及判定依据
排雷阈值变体：底部净现比可为负属常态、穿越周期看毛利率区间而非单期、主动补库存不必然是坏事（redflags 行业变体已定）；另盯存货跌价准备转回带来的利润虚增、在建工程长期不转固、资本化利息占比、关联方原料采购定价
典型悬空点：「正常化 ROE」取几年、「中枢 PE」取哪一轮都是自定的，属私有基准；价差与成本曲线数据多来自付费资讯终端，公开可回溯的往往只有交易所期货价，属外部但口径存疑

## 3. 稳态现金流型

归属判据：需求稳定且可预测，品牌与渠道构成壁垒，资本开支轻，经营现金流常年不低于净利润，量价缓增而无周期反转（典型：白酒、调味品、家电、必需消费）
主估值方法：PE（TTM 与前瞻并列）+ 股息率，辅以 DCF 交叉验证（此型是少数永续增长假设站得住的原型）
失效指标：
  - PS——净利率既高又稳，收入倍数丢掉了盈利能力这一层信息，横比无意义
  - PB——品牌不入表、账面净资产多为现金与厂房，PB 高不代表贵、低不代表安全
  - EV/EBITDA——折旧极小，与 PE 高度共线，不提供增量信息
必比口径：
  - 板块 PE_TTM 中位数与本票近五年 PE 分位（本地 peers_curated.json 的 PE_TTM 中位数直取）
  - 板块股息率与分红率中位数
  - 板块毛利率与净利率中位数（按价格带分档：高端 / 次高端 / 大众）
  - 板块合同负债（预收账款）占季度收入比中位数
  - 板块经营现金流 / 净利润 中位数
必做分析：吨价与销量分拆、批价与渠道库存周转天数、经销商数量与单商产出、历史提价幅度与传导时滞、品类天花板与人均消费量的国际对标、渠道结构变化（直营 / 电商 / 团购占比）
排雷阈值变体：应收应该低（现结），高就是警讯；预收 / 合同负债是需求前瞻信号，环比下滑先于收入下滑（redflags 行业变体已定）；另盯渠道压货造成的收入前置、销售费用率突然下降、其他应收款与预付款异常、关联经销商
典型悬空点：批价与渠道库存多为草根调研口径，无公开可回溯来源，属外部但口径存疑；「品牌溢价」常被用来解释估值高于板块，但它本身没有可量化的外部基准

## 4. 成长渗透型

归属判据：单品或单技术的渗透率仍在爬坡，收入增速数倍于 GDP，竞争格局未定、份额可迁移，盈利可能已转正但尚不稳定（典型：半导体设计、新能源车、光伏、创新硬件）
主估值方法：前瞻 PE 三情景（行业规模 × 市占率 × 净利率 → 目标年净利 × 倍数 → 市值），尚未盈利的阶段用 PS / EV-Sales 过渡，PEG 只作辅助
失效指标：
  - 当期 PE——研发费用化压低当期利润且增速拐点未定，静态倍数没有参照意义
  - PB——轻资产（设计类）分母近于募资余额，重资产（光伏 / 电池）分母被扩产摊薄，两端都失真
  - 单季营收环比——受排产与订单节奏扰动，最容易被误读成趋势
必比口径：
  - 板块前瞻 PE 中位数（须按同一盈利年度对齐，不得与 TTM 混比）
  - 板块 PS / EV-Sales 中位数（未盈利同业单独成组取，不与已盈利同业混算）
  - 板块增速中位数与 PEG 中位数
  - 板块研发费用率中位数
  - 板块毛利率中位数（按环节分档：设计 / 制造 / 组装）
必做分析：渗透率所处 S 曲线位置、行业规模自上而下与自下而上双算并对齐差异、市占率来源拆分（存量替代 or 增量新增）、alpha / beta 切分（增长里多少来自景气、多少来自新品能力）、设计一个比业绩更早出现的领先指标（framework.md 第十节）、三情景拆到产品线而非只做公司层面
排雷阈值变体：存货与应收随收入同步放大属常态，看的是周转天数是否恶化；研发资本化率是首要红旗（同业普遍费用化时的资本化即警讯）；另盯政府补助与所得税优惠占利润比、股份支付摊销对净利率的侵蚀、大客户集中度与预付大额设备款
典型悬空点：「行业规模」与「目标市占率」两个承重数往往只有一家第三方咨询机构的口径，属外部·单源未交叉；三情景的假设本身无同业可比，属私有基准

## 5. 研发管线型

归属判据：价值集中在尚未上市的品种及其成功概率上，当期收入与内在价值弱相关甚至无关，现金流形态由临床阶段与融资节奏决定（典型：创新药、生物科技、疫苗）
主估值方法：rNPV / 风险调整 DCF（逐品种 × 成功概率 × 峰值销售 × 折现），辅以现金跑道与可比交易法
失效指标：
  - PE——利润为负，或由一次性 license-out 首付款拼成，分母不可持续
  - PS——产品销售与授权首付款不同质，收入倍数横比等于把两种生意混算
  - PB——研发全额费用化后净资产近似于账上现金，PB 实际是在测「还剩多少钱」
必比口径：
  - 板块 市值 / 净现金 中位数（扣掉现金后市场给管线本身的定价）
  - 板块 EV / 在研品种数 中位数（按最高临床阶段分档：临床前 / I 期 / II 期 / III 期 / 已报产）
  - 同靶点同适应症 license-out 交易的首付款与里程碑总额区间（可比交易法）
  - 同阶段临床成功率的行业统计分位（用来校准自算 rNPV 里的概率假设）
  - 板块研发费用率与现金跑道（月）中位数
必做分析：逐品种管线表（靶点 / 适应症 / 阶段 / 竞争位次 / 预计上市年）、峰值销售自下而上测算（患者基数 × 诊断率 × 渗透率 × 年治疗费 × 支付能力）、医保谈判降价幅度历史、专利到期与数据保护期、现金 ÷ 年经营净流出 算跑道、license-out 条款拆解（首付 / 里程碑 / 销售分成分别折现）
排雷阈值变体：研发资本化是首要红旗（同业普遍费用化）；另盯里程碑收入确认时点与合同条款是否匹配、关联方 CRO / CDMO 交易定价、股权融资摊薄速度、license-in 形成的商誉与无形资产减值假设、临床数据只披露亚组与替代终点
典型悬空点：成功概率、峰值销售、折现率三个假设都是自定的，属私有基准；公司引用的第三方市场规模通常无法交叉验证，属外部·单源未交叉

## 6. 平台网络型

归属判据：边际成本近零，用户与商户两端存在网络效应，收入随 GMV 或订阅席位放大，获客支出前置而收益递延（典型：互联网、SaaS、交易平台）
主估值方法：EV/Sales 与 EV/ARR（SaaS 用 Rule of 40 定位倍数），成熟期转 EV/EBITDA 或分部 SOTP，长期利润率假设由 LTV/CAC 支撑
失效指标：
  - PE——早期补贴与股份支付压低利润，且 GAAP 利润与自由现金流长期背离
  - PB——无形资产与用户资产不入表，账面净资产无意义
  - 未还原口径的 PS——收入按总额法还是净额法确认可差数倍，跨家横比前必须先还原
必比口径：
  - 板块 EV/Sales 与 EV/ARR 中位数（按增速分档：>30% / 15–30% / <15%）
  - 板块 Rule of 40 分位（收入增速 + 自由现金流率）
  - 板块净收入留存率（NDR / NRR）中位数
  - 板块获客成本回收期（CAC payback，月）中位数
  - 板块 take rate（货币化率）中位数
必做分析：MAU / DAU 与 ARPU 分拆、take rate 变动来源、留存曲线与同期群（cohort）分析、单位经济模型 LTV/CAC、网络效应是全局的还是局部的（同城 / 同品类）、平台监管与佣金上限、新入口（AI、短视频）对流量分发的重构
排雷阈值变体：递延收入与合同负债是收入的先行指标，环比转负先于报表恶化；另盯股份支付占收入比与 non-GAAP 调整的激进程度、收入总额法虚增 PS、资本化的用户获取成本、关联方流量采买、投资收益与被投企业公允价值变动占利润比
典型悬空点：NDR、CAC、留存率多为公司自披露且各家定义不同，属外部但口径存疑；take rate 的分母 GMV 通常无第三方验证，属私有基准

## 7. 项目制工程型

归属判据：按项目或订单交付，收入按完工进度确认，回款系统性滞后于收入，在手订单是主要前瞻变量（典型：建筑、工程设备、系统集成、军工总装）
主估值方法：PE（以在手订单可转化的可见盈利为基础）+ 订单 / 市值 修正，资产负债表脆弱时用 PB 设下限
失效指标：
  - 单期经营现金流——进度法下现金流本就滞后于利润，单期为负不足以定罪，但连续多年净现比 <0.5 是真警讯
  - PS——总包与分包口径不同，收入含转包部分，跨家不可比
  - 毛利率横比——甲供材 / 清包工 / EPC 口径差异可造成十个点以上的系统性偏差
必比口径：
  - 板块 PE_TTM 与 PB 中位数（本地 peers_curated.json 直取）
  - 板块在手订单 / 年收入 倍数（订单覆盖率）中位数
  - 板块（应收账款 + 合同资产）/ 收入 比与应收周转天数中位数
  - 板块应收账款坏账准备计提率中位数（用来判断本票计提是否充分）
  - 板块净现比（经营现金流 / 净利润）中位数
必做分析：在手订单结构（新签 / 存量 / 毛利率）、政府与国企客户占比、应收账龄分布与回款周期、完工百分比的计量基础与变更历史、PPP / BOT 项目的表内外安排与投资回收期、军工的定价机制（成本加成 vs 竞价）与审价回溯风险
排雷阈值变体：应收 / 合同资产高是模式使然，看账龄与减值；进度法确认收入 → 现金流滞后于利润（redflags 行业变体已定）；另盯完工进度估计变更带来的利润调节、质保金长期挂账、已完工未结算长期不结转、少数股东损益异常、对外担保与代垫工程款
典型悬空点：在手订单口径各家不一（是否含框架协议、是否含税、是否含未生效中标），无统一外部基准；军工客户与定价不披露，同业毛利率差异无法归因，属外部但口径存疑

## 8. 金融息差型

归属判据：以资产负债表规模与利差为利润来源，受资本充足率硬约束，风险成本递延且可通过拨备平滑（典型：银行）
主估值方法：P/B × 可持续 ROE（辅以剩余收益模型或 DDM），估值必须与资产质量假设绑定给出
失效指标：
  - 毛利率与营业成本类指标——报表结构不适用（redflags 行业变体已定：看不良率、资本充足率、拨备覆盖率，而非毛利率）
  - PE——拨备计提是平滑利润的旋钮，当期利润可调，PE 因此可被管理
  - EV/EBITDA——负债是经营性的，企业价值口径在此不成立
必比口径：
  - 板块 PB 中位数（按类型分档：国有大行 / 股份行 / 城商行 / 农商行）
  - 板块 ROE 与 ROA 中位数
  - 板块净息差 NIM 与生息资产收益率、计息负债成本率中位数
  - 板块不良率、关注类占比、逾期 90 天以上 / 不良 中位数
  - 板块拨备覆盖率、拨贷比与核心一级资本充足率中位数
  - 板块成本收入比中位数
必做分析：生息资产结构与重定价缺口、负债成本与活期存款占比、不良生成率与核销规模还原真实资产质量、房地产 / 城投 / 零售各敞口占比与迁徙、中间业务收入结构、资本充足与再融资需求测算、区域经济与客群绑定度
排雷阈值变体：常规九项排雷单整体不适用；改看不良偏离度（逾期 90 天以上 / 不良 >1 为警讯）、拨备覆盖率变动方向与利润增速的反向关系（反向即为利润平滑）、非标与表外理财回表压力、以量补价掩盖息差收窄、贷款行业与单一最大客户集中度、重组贷款与展期占比
典型悬空点：真实不良率没有外部可回溯来源，只能用逾期偏离度与核销规模间接推断，属无参照系；拨备的逆周期调节使 ROE 的可持续性无法从报表验证

## 9. 金融承保型

归属判据：先收保费后付赔款，负债端由精算假设决定，投资端赚取利差，利润确认高度依赖假设而非现金收付（典型：保险）
主估值方法：寿险用 P/EV 与新业务价值倍数（市值 = EV + NBV × 倍数 反推隐含倍数），财险用 P/B × ROE 并与综合成本率联读
失效指标：
  - PE——新准则下利润受投资波动与合同服务边际摊销影响，年际不可比
  - 保费收入增速——规模保费含趸交与万能账户，与价值增长可长期背离
  - PB——净资产受金融资产公允价值变动扰动，且不含未来保单利润
必比口径：
  - 板块 P/EV 中位数与本票近五年 P/EV 分位
  - 板块新业务价值率（NBV margin）与 NBV 增速中位数
  - 板块内含价值营运回报率（operating ROEV）中位数
  - 财险板块综合成本率 COR 中位数及赔付率 / 费用率分拆中位数
  - 板块投资收益率（净 / 总 / 综合）中位数，以及行业通行的长期投资回报率与风险贴现率假设
  - 板块偿付能力充足率（核心 / 综合）中位数
必做分析：EV 对投资回报率与风险贴现率的敏感性表、假设变动与经验偏差对 EV 增长的贡献拆解、代理人数量 × 人均产能分拆、期缴与趸交结构及缴费期限、13 个月与 25 个月继续率、准备金折现率对利润的影响（**先确认标的所处准则年代再选口径**：旧准则下为 750 日国债收益率移动平均，折现率变动直接冲当期利润；IFRS 17 / 新保险合同准则下折现率变动多计入 OCI，利润端由 CSM 摊销决定，两者不可混用也不可跨年混比）、资产负债久期缺口
排雷阈值变体：常规九项不适用；改看精算假设是否长期不下调（长期投资回报假设高于同业即警讯）、准备金评估假设变更对当期利润的贡献额、退保率与继续率背离、非标资产占投资资产比与信用敞口、分红险特别储备的调节空间、再保安排是否用于粉饰 COR
典型悬空点：EV 与 NBV 由公司自聘精算师计算，第三方无法复算，天然属私有基准；非标投资资产的估值无公开可回溯来源

## 10. 金融资本型

归属判据：收入随市场成交量与资产价格波动，以自有资本加杠杆做投资与融出，业务边界由牌照决定（典型：券商、多元金融）
主估值方法：P/B × 穿越牛熊的正常化 ROE，辅以分部 SOTP（经纪 / 自营 / 资管 / 投行 / 信用各给倍数）
失效指标：
  - PE——自营损益随市值波动，牛市利润虚高、熊市虚低，与周期股同病
  - 毛利率——不适用（redflags 行业变体已定）
  - 营业收入增速——含其他业务收入（大宗商品交易按总额法），可数倍虚增，须用营业收入剔除其他业务后再比
必比口径：
  - 板块 PB 中位数与近十年 PB 分位（本地 peers_curated.json 的 PB 中位数直取）
  - 板块 ROE 中位数（牛市年度与熊市年度分开取，不得跨市况混算）
  - 板块杠杆率中位数（剔除客户保证金后的权益乘数）
  - 板块各业务线收入占比中位数（经纪 / 自营 / 资管 / 投行 / 信用）
  - 板块净佣金率、两融市占率与资管 AUM / 市值 中位数
必做分析：日均成交额与佣金率对利润的弹性测算、自营资产结构（权益 / 固收 / 衍生对冲）与方向性敞口、两融余额与股票质押风险敞口、投行在审项目数与撤否率、资管主动管理占比、监管资本约束（风险覆盖率、净稳定资金率）与再融资节奏
排雷阈值变体：常规九项不适用；改看自营公允价值层级（第三层级资产占比）、股票质押减值计提充分性、其他业务收入的总额法虚增、表外资管产品的刚兑与代偿风险、单一客户融出集中度、场外衍生品名义本金增速
典型悬空点：自营敞口方向与对冲比例不披露，ROE 波动无法归因，属无参照系；第三层级资产的估值属私有基准

## 11. 重资产公用型

归属判据：一次性重资本开支换长期稳定收费权，价格受管制或由特许经营协议约定，需求近似刚性，折旧与财务费用主导成本结构（典型：电力、水务、燃气、高速、机场、铁路）
主估值方法：EV/EBITDA + 股息率（DDM），特许经营期有限的用项目 DCF 并在到期日归零
失效指标：
  - PE——折旧年限与资本化政策各家差异大，PE 不可比（framework.md 已定）
  - PB——重估口径与历史成本口径并存，且旧资产账面已折旧近零，PB 高不等于贵
  - 毛利率横比——折旧是否计入营业成本各家不同，先还原口径再比
必比口径：
  - 板块 EV/EBITDA 中位数（按资产类型分档：火电 / 水电 / 绿电 / 高速 / 机场 / 燃气）
  - 板块股息率与分红率中位数
  - 板块 ROIC 中位数与板块加权融资成本（用于判断投资回报是否覆盖资金成本）
  - 单位产能造价与单位 EBITDA 的板块中位数（元 / 千瓦、元 / 公里、元 / 旅客、元 / 立方）
  - 板块折旧年限与资产负债率中位数（用来把 PE 与毛利率还原到可比口径）
必做分析：电价 / 水价 / 气价 / 通行费的调价机制与历史调价幅度、利用小时数与流量增长、特许经营剩余年限与到期资产归属安排、资本开支周期与在建转固节奏、有息负债久期与利率敏感性、可再生能源补贴应收的回款进度、来水来风来光的自然波动区间
排雷阈值变体：折旧政策、在建转固、资本开支强度是排雷重点（redflags 行业变体已定）；另盯折旧年限长于同业、在建工程长期挂账不转固、资本化利息占比、大修支出资本化、补贴应收账龄与减值、少数股东权益中的项目层结构化融资
典型悬空点：特许经营期满后的资产处置价值与续约条款常无明确外部依据，属无参照系；折旧年限的合理性缺乏统一外部基准，横比前需自行调整口径，属外部但口径存疑

## 12. 地产存货型

归属判据：买地—开发—预售—交付结转，收入确认滞后销售两到三年，土地储备是核心资产，杠杆与预售监管资金决定生死（典型：房地产开发）
主估值方法：分项目重估的 NAV 与 P/NAV，辅以 PB 设下限；出险或清算情景下改用可售货值折价
失效指标：
  - PE——结转的是两三年前的销售，当期 PE 反映历史景气，与当下拿地与销售脱节
  - 收入增速与结算毛利率——同样滞后，且被历史地价锁定，不能当作经营现状
  - PB——存货按成本计量，地价下行期账面净资产未反映减值，低 PB 是假象
必比口径：
  - 板块 P/NAV 与 NAV 折价率中位数（按性质分档：央国企 / 优质民企 / 出险企业）
  - 板块 PB 中位数与近五年 PB 分位
  - 板块已售未结金额 / 年收入 倍数（未来收入锁定度）中位数
  - 板块净负债率、现金短债比、剔除预收后的资产负债率中位数（三条红线口径）
  - 板块土储平均楼面价 / 当期销售均价 之比与存货跌价准备计提比例中位数
必做分析：土储按城市能级分布与去化周期、已售未结货值与对应结转毛利率区间、销售回款率与预售资金监管额度、境内外债券到期分布与再融资通道、少数股东权益占比与明股实债识别、合联营公司表外负债、重点城市房价与库存去化月数
排雷阈值变体：常规存货周转率不适用（开发周期本就以年计）；改看存货跌价准备计提是否覆盖地价跌幅、少数股东损益 / 净利润 与 少数股东权益 / 所有者权益 长期背离（明股实债信号）、其他应付款中的关联方往来、经营现金流转正是否靠停止拿地换来、对外担保余额占净资产比、商票逾期
典型悬空点：NAV 的项目层假设（售价、去化速度、折现率）多为自算，属私有基准；表外合联营负债规模无法从公开报表还原，属无参照系

## 13. 持有型不动产

归属判据：持有已建成物业收租，收入 = 可租面积 × 租金 × 出租率，资产价值 ≈ NOI ÷ 资本化率（cap rate）——对租金同向、对 cap rate 严格反向，分派现金流是核心诉求（典型：REITs、商业地产、物流仓储）
主估值方法：P/NAV（以第三方评估的物业公允价值为基座）+ 分派率，并用 cap rate 反推市场隐含的资产定价
失效指标：
  - PE——投资性房地产公允价值变动计入利润，评估值一变利润就变，与经营无关
  - EPS 与利润增速——同被重估损益污染，须用 FFO / AFFO 替代
  - PS——收入即租金，稳定但与资产价值不成固定比例，倍数无信息量
必比口径：
  - 板块 P/NAV（相对每股 NAV 的溢价或折价）中位数，按业态分档：购物中心 / 写字楼 / 物流仓储 / 产业园 / 保租房
  - 板块分派率（可供分派金额 / 市值）中位数，及其与十年期国债收益率的利差
  - 同城市同业态市场化大宗交易的 cap rate 中位数
  - 板块 P/FFO 与 P/AFFO 中位数
  - 板块出租率、租金单价（元 / 平方米 / 天）与同店租金增速中位数
必做分析：同店 NOI 增速与 NOI 率、租约到期分布与租金调整条款、租户结构与前十大租户集中度、单项目运营成本与管理费率、扩募或外部收购的每股增厚测算、加权融资成本与 cap rate 的正负利差、评估机构 cap rate 假设的年度变动
排雷阈值变体：毛利率与存货类指标不适用；改看投资性房地产计量模式（公允价值 vs 成本）、评估增值对净资产与利润的贡献比、可供分派金额与经营现金流的差额构成、资本化利息、租金收入中一次性补偿与免租期摊销的处理、关联方承租与保底租金安排
典型悬空点：cap rate 与物业评估值由公司聘请的评估机构出具，同一物业不同机构可差十个百分点以上，属私有基准；可比大宗交易案例稀少且成交价常不公开，属外部·单源未交叉

## 14. 渠道分销型

归属判据：低毛利高周转，赚差价与账期，收入体量巨大而净利率极薄（常低于 3%），营运资金占用是主要的资本投入（典型：医药商业、汽车经销、3C 分销、大宗贸易）
主估值方法：PE（低倍数中枢）+ EV/EBIT，并用杜邦拆解验证 ROE 由周转率而非净利率驱动；资金占用重的辅以 EV / 营运资金
失效指标：
  - PS 与收入增速——总额法确认收入时收入体量与价值无关，与净额法同业可差数十倍
  - 毛利率横比——代理 / 买断 / 寄售模式不同，毛利率天然不可比
  - PB——存货与应收占资产大头，账面净资产质量完全取决于减值假设
必比口径：
  - 板块 PE_TTM 与 PB 中位数（本地 peers_curated.json 直取，取用前须确认同业收入确认模式一致）
  - 板块净利率与期间费用率中位数（按确认模式分档：总额法 / 净额法）
  - 板块存货周转天数、应收周转天数、应付周转天数与现金转换周期 CCC 中位数
  - 板块 ROE 与总资产周转率中位数（杜邦口径，本型看周转率）
  - 单店 / 单车 / 单品类毛利额的板块中位数（汽车经销另取新车毛利与售后毛利占比中位数）
必做分析：上游厂商返利政策与返利确认时点、账期结构与供应链金融（保理、票据）使用规模、集采与两票制等政策对渠道层级的压缩、单店模型与网点扩张的边际回报、大宗贸易的价格敞口与套保比例、客户与供应商集中度及是否同一控制人
排雷阈值变体：应收高是模式使然，看账龄与减值；单一主业大存大贷是警讯（redflags 已定）；另盯无商业实质的走单与融资性贸易（收入大增而毛利率趋零、存货不落地、上下游关联）、票据与保理是否实现出表、返利冲减成本的确认节奏、预付款长期挂账
典型悬空点：收入按总额法还是净额法各家披露粗糙，横比前的口径还原只能靠估算，属外部但口径存疑；厂商返利政策不公开，同业毛利率差异无法归因，属无参照系

## 15. 亏损未验证型

归属判据：商业模式尚未被现金流验证——收入极小或为零、经营现金流持续为负，估值主要由叙事与融资节奏决定（典型：次新未盈利公司、pre-revenue 生物科技、早期科技）
主估值方法：PS / EV-Sales + 现金跑道（现金 ÷ 年经营净流出）；无收入的改用可比一级市场融资估值与技术里程碑法（framework.md 已定：无正 EPS，PE 无意义）
失效指标：
  - PE 与 PEG——分母为负或近零，数学上无意义，出现即为口径错误
  - PB——净资产等于募集资金余额，PB 是在测「还剩多少钱」，不是在测价值
  - EV/EBITDA——EBITDA 为负，倍数是负数，不可读也不可比
必比口径：
  - 板块 EV/Sales 中位数（限定同样未盈利的子集，与已盈利同业分开取）
  - 同赛道最近一轮一级市场融资的投后估值区间（可比交易法）
  - 板块现金跑道（月）与年经营净流出中位数
  - 板块研发费用率与研发投入绝对额中位数
  - 板块上市以来累计摊薄比例中位数（增发、可转债、股权激励合计）
  - 板块 市值 / 累计研发投入 中位数（无收入时的替代锚）
必做分析：现金跑道测算（账上现金及等价物 ÷ 最近四个季度经营净流出）与下一轮融资窗口、盈亏平衡点测算（固定成本 ÷ 单位贡献毛利）、第一个可验证的商业化里程碑及其时间表、订单与意向合同的历史兑现率、核心团队与技术来源（自研 / 授权 / 高校转化）、科创板与港股 18A、18C 等特殊上市规则下的退市与转板条件
排雷阈值变体：常规盈利质量指标全部不适用；改看现金消耗速率的环比变化、研发资本化率（此型出现资本化即重大警讯）、政府补助与税收返还占收入比、关联方交易贡献的收入、存货与应收突然出现（收入真实性）、股份支付规模、募集资金变更用途与理财占比
典型悬空点：一级市场估值、峰值市场规模、盈亏平衡时点等所有估值锚都是自定或单源，属私有基准或外部·单源未交叉；未盈利同业的可比集样本极小，中位数本身不稳健
