# lens：竞争格局

> equity-thesis-cn 的竞争子 agent 读本文件执行。覆盖第七节（全文最重的一节）。
> 定位：份额、竞对对照、海外对标、把份额变动归因到事件。骨架细节见 `../framework.md` 第七节。

## 读什么

- `data/{SYMBOL}/peers.json`（同业池——常只有公司自身一条，要标注这个局限）
- `data/{SYMBOL}/annual_pdf/*.pdf` 的"行业竞争/市场地位/分部经营"章节（Read pages 参数）
- `data/{SYMBOL}/aggregate.json` 的 business

## 关键动作（六问里挑 3–4 个与本票最相关的深答）

1. **份额与排名**：分板块给，别只给一个总数。多元公司要拆到各分部。

2. **竞对逐项对照表**：外资/本土、是否上市、直接竞争业务、市占率、知名客户、优势、财务。
   - 竞对未披露的数据**可反算**，但标注方法（澜起："瑞萨的内存接口收入为按市占率反算"）。
   - 承认调研缺口（中控："康吉森没找到具体对比，但从经营范围看产品单一"）——不要假装查全了。

3. **份额变动归因到事件**，不要只给曲线：
   - 人事（澜起：IDT 副总裁 Sean Fan 离职加入 Rambus，带走有粘性的客户 → Rambus 份额跳升）。
   - 并购/政策（美的库卡份额被本土埃斯顿反超）。

4. **海外对标反推**（常最有用）：找可对标的国际龙头，用它的历史路径反推本票的演进方向与估值锚。
   - 中控：西门子/艾默生"从硬件起步、近年大规模收购软件厂商" → 反推中控要走综合解决方案。
   - 美的：西门子/霍尼韦尔的"工业集团溢价"出现在**聚焦-分拆-独立验证之后**，而非做加法阶段 → 解释美的为何暂无溢价。

5. **关键成功要素**（牌照/低成本/研发/营销/渠道/自然资源里选），分 ToC/ToB 说。

   **说竞争力时用排他事实，不用形容词。** "技术领先""产品优异"不可证伪，
   而"只有几家能做到"是可以回原文核对的。三份底稿的取法：
   - **能力排他**：澜起"当前仅澜起科技、IDT 具备内存接口芯片及其配套芯片的全套产品供应能力"
   - **等级排他**：开立"目前国产品牌仅有 2016 年开立推出的 HD-500 能够进入到 1080P 高清内镜级别"
   - **名单排他**：乐鑫"Google 推出云物联网设备 SDK，乐鑫是其首发的 5 家芯片合作伙伴之一……
     首批通过 ACS 认证的硬件平台有 ESP32 和 RPi4"

   三者的共同形状是**"在某个具体门槛上，全世界/全国只有 N 家（含本公司）"**，且 N 可查、门槛可查。
   找不到这样的事实，就说明所谓竞争力还没有被第三方验证过——那就如实写"没有找到排他性证据"，
   而不是退回形容词。

6. **卖方共识的修正史与覆盖度**（本 lens 的必做项，数据在 `aggregate.json` 的 `research_reports`）。

   不要只取最新一期的一致预期当参照系——**要把同一个目标年的预测按发布时间排开，看它是怎么被改的**：

   | 发布时间 | 对 20XX 年 EPS 的预测 |
   |---|---|
   | 两年前 | 1.87 – 2.05 |
   | 一年前 | 1.09 – 1.33 |
   | 半年前 | 0.92 – 1.11 |
   | 最近 | 0.71 – 0.85 |

   这是 300633 的真实序列：**两年里把同一年的预测砍掉约 60%，而评级始终是买入/增持。**

   > **这一条目前只有一个观测样本（300633），且 5 份人工底稿无一做过共识修正史。**
   > 因此下面这句只作为待验证的读法，不作为定论：一个被系统性、单向下修的一致预期，
   > 其当期值可能不宜直接当锚。**在积累到第二、第三个样本之前，本条只要求把修正过程摆出来，
   > 不要求据此改写估值锚。** 摆出来之后由写稿人自己判断，并在正文说明判断依据。

   要算的两个数：
   - **兑现率**：往期预测 vs 实际，差多少。这是给这批分析师的信用打分。
   - **当期共识的算术压力**：把全年共识减去已披露的季度实际，反推剩余季度需要的同比增速。300633 那次算出来是"26Q2–Q4 需同比 +75.7%"——**这个数比共识本身有信息量得多**。

   **覆盖度本身是信号。** 开立那份人工底稿的原话："19 年中之后，研报基本没有这家公司，业绩目前的预期还不好，没有人愿意碰。" 无人覆盖 = 逆向布局窗口；覆盖突然变密 = 预期已被计入。近一月研报数在 `research_reports` 里有字段，取出来看趋势。

   **如果公司有股权激励方案，把方案的业绩目标折算成利润额，和卖方共识摆在一起。** 内部人设的目标与外部人给的预测出现系统性差距时，这个差距本身就是判断依据（300633：公司自设 2026 年目标约 2.32 亿 vs 卖方共识 3.21 亿，低 28%）。这条要与战略驱动子 agent 交叉——激励方案原文由它负责挖。

## 输出契约

先把完整发现写到 `reports/{SYMBOL}_thesis_{报告日}/findings/竞争.md`，再返回：

```
## 发现（事实，带出处）
## 判断要点（bullet，含"不确定"项）
## 建议进档案（假设 / 未决疑问）
```

数据反算和"没找到对比"都如实标注。peers.json 只有自身一条时明说这个局限。不写观点总结散文。
