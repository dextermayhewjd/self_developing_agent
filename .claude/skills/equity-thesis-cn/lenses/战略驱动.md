# lens：战略驱动（募投 / 战略 / 未来驱动）

> equity-thesis-cn 的战略子 agent 读本文件执行。覆盖第八、九、十节。
> 定位：判增长路径、设计领先指标、切分 alpha/beta。骨架细节见 `../framework.md` 第八/九/十节。

## 读什么

- `data/{SYMBOL}/annual_pdf/*.pdf` 的"公司战略/发展规划/募投项目/展望"章节（Read pages 参数）
- `data/{SYMBOL}/earnings_call.json`（业绩说明会 + **投资者关系活动记录表——当半一手素材优先挖**，标注日期）
- `data/{SYMBOL}/aggregate.json`、`news.json`（**并购/分拆/员工持股公告常在这里，翻标题**）

## 关键动作

1. **募投/资本开支去向**：围绕主业还是跨界？跨界成功概率？允许批评历史决策（石基："我都不明白软件商去搞医疗器械销售，成功概率很低"）。留意资本承诺的变化（美的资本承诺 113.5 亿→39.2 亿 = 并购节奏放缓的信号）。

2. **增长路径分类**（外延收购/横向拓展/相关多元化/纵向一体化/国际化里逐条判断走哪条为主）。

   **处理公司的战略/研发/进展表述，走两步，缺一不可：**
   1. **原样引用，一个字不改。** 这是日后拿实际进展去对照的基准，改写过就不能当基准用了。
   2. **紧接着用自己的话翻译或概括一句，并检查两者对不对得上。** 翻译不出来，
      说明这段话本身是形容词堆砌；翻译出来但和原文对不上，说明你读的是自己想读的东西。

   底稿的做法：石基照抄公司云平台战略原文后写"上述这段话概括要酒店系统为什么要上云平台，
   上了云平台后，数据能活化……"；澜起逐条抄完"未来三年的发展目标"四条后写"可以看到，
   公司整体策略是在内存接口芯片领域稳住基本盘并有所提升的基础上，不断开拓第二曲线"。

   **只做第 1 步不做第 2 步是最常见的偷懒**（实测中控那份就是整段照抄后直接进下一节）——
   照抄一段公司原话不构成分析，它只是把举证责任推给了读者。

3. **设计一个领先指标**（本 lens 最有价值的动作）——找比业绩更早出现的验证信号：
   - 石基："餐饮分部收入下降 → 推断转 SaaS 年费模式 → 这是酒店 PMS 云化的排头兵"。
   - 美的："库卡中国分拆后的独立披露 → 首次揭示国产替代真实兑现"。

4. **翻公告找拐点事件**：并购、分拆、员工持股常预示战略动作。美的这次的决定性变量更新，就来自战略子 agent 翻到 news.json 里"2026-06-16 分拆子公司至港交所上市进展"公告——编排器视角容易漏，子 agent 专职翻才翻得到。

5. **研发投入的质量三查**（固定项，必查——实测两次都靠临时想起才做，必须固化）：

   - **研发支出资本化率**。资本化研发是 A 股最省力的利润美化手段：把费用挪进资产负债表，当期利润立刻好看。
     **必查项是"这家公司的研发怎么记账"，把口径写出来**（澜起底稿："研发费用率维持在 15% 以上，
     研发支出全部费用化"；石基底稿在重算研发费用率时把资本化研发加回分子，等于交代了它存在资本化）。
     资本化率高或突然抬升，是减分项，要问为什么。
     **反过来，连续多年 0.00% 说明利润没有被这个手段撑起来，是一条干净的事实——
     但不要据此加分。** 人工底稿里确认过会计处理的两份，都只把它当事实陈述、
     与公司属性对齐（IC 设计公司研发即核心驱动），没有一份把它写成正面信号或计入评分。
   - **研发人员数量与研发支出的背离**。支出涨而人数不涨（甚至下降），说明不是靠堆人头做数；人数暴涨而产出无变化，是另一回事。
   - **产出的可数证据**：新增注册证/专利/型号认证数量、进入下一世代的量产准备情况。**费用是投入，这些才是产出**——没有产出证据的费用增长，只能算费用，不能算投资。

6. **Alpha/Beta 切分**：增长里多少靠自身能力、多少靠行业景气？（乐鑫："抓 alpha 能力有限，更依赖行业 beta"；美的："楼宇 25.72% 含并表，是用并购制造表观 alpha"）。

## 输出契约

先把完整发现写到 `reports/{SYMBOL}_thesis_{报告日}/findings/战略驱动.md`，再返回：

```
## 发现（事实，带出处）
## 判断要点（bullet，含"不确定"项）
## 建议进档案（假设 / 未决疑问）
```

earnings_call.json 的调研纪要是半一手，优先挖并标日期。news.json 的公告标题要翻（找并购/分拆/持股）。查不到的直说，不写观点总结散文。
