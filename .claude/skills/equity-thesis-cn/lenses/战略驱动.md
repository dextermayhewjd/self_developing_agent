# lens：战略驱动（募投 / 战略 / 未来驱动）

> equity-thesis-cn 的战略子 agent 读本文件执行。覆盖第八、九、十节。
> 定位：判增长路径、设计领先指标、切分 alpha/beta。骨架细节见 `../framework.md` 第八/九/十节。

## 读什么

- `data/{SYMBOL}/annual_pdf/*.pdf` 的"公司战略/发展规划/募投项目/展望"章节（Read pages 参数）
- `data/{SYMBOL}/earnings_call.json`（业绩说明会 + **投资者关系活动记录表——当半一手素材优先挖**，标注日期）
- `data/{SYMBOL}/aggregate.json`、`news.json`（**并购/分拆/员工持股公告常在这里，翻标题**）

## 关键动作

1. **募投/资本开支去向**：围绕主业还是跨界？跨界成功概率？允许批评历史决策（石基："我都不明白软件商去搞医疗器械销售，成功概率很低"）。留意资本承诺的变化（美的资本承诺 113.5 亿→39.2 亿 = 并购节奏放缓的信号）。

2. **增长路径分类**（外延收购/横向拓展/相关多元化/纵向一体化/国际化里逐条判断走哪条为主）。

3. **设计一个领先指标**（本 lens 最有价值的动作）——找比业绩更早出现的验证信号：
   - 石基："餐饮分部收入下降 → 推断转 SaaS 年费模式 → 这是酒店 PMS 云化的排头兵"。
   - 美的："库卡中国分拆后的独立披露 → 首次揭示国产替代真实兑现"。

4. **翻公告找拐点事件**：并购、分拆、员工持股常预示战略动作。美的这次的决定性变量更新，就来自战略子 agent 翻到 news.json 里"2026-06-16 分拆子公司至港交所上市进展"公告——编排器视角容易漏，子 agent 专职翻才翻得到。

5. **Alpha/Beta 切分**：增长里多少靠自身能力、多少靠行业景气？（乐鑫："抓 alpha 能力有限，更依赖行业 beta"；美的："楼宇 25.72% 含并表，是用并购制造表观 alpha"）。

## 输出契约

先把完整发现写到 `reports/{SYMBOL}_thesis_{报告日}/findings/战略驱动.md`，再返回：

```
## 发现（事实，带出处）
## 判断要点（bullet，含"不确定"项）
## 建议进档案（假设 / 未决疑问）
```

earnings_call.json 的调研纪要是半一手，优先挖并标日期。news.json 的公告标题要翻（找并购/分拆/持股）。查不到的直说，不写观点总结散文。
