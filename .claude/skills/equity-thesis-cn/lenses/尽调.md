# lens：尽调（公司简介 / 股权 / 高管）

> equity-thesis-cn 的尽调子 agent 读本文件执行。覆盖第一、二、三节。
> 定位：回答"谁控制公司、谁管公司"，把名单读成信号。骨架细节见 `../framework.md` 第一/二/三节。

## 读什么

- `data/{SYMBOL}/governance.json`（十大股东）
- `data/{SYMBOL}/aggregate.json` 的 business
- `data/{SYMBOL}/annual_pdf/*.pdf` 的"公司治理/股东/董监高"章节（Read pages 参数）

## 关键动作（不是罗列，是读信号）

1. **收入结构 + 产业阶段**：按发展阶段分段，不要流水账。留意公司对自身阶段的官方定性（如美的年报自陈"成熟期"——这一句定全文调）。

   **收入占比不是罗列，是用来框定研究范围的**：按占比从大到小累加，累到覆盖绝大部分收入为止，
   然后**明写一句"后续只盯这几块"**，把剩下的零头业务排除出全篇。
   石基："第三方硬件配套（33%）、酒店信息管理系统（32%）、商业流通管理系统（15%）、
   自主智能商用设备（13%），**四块业务合计占总收入的 93%**"；
   乐鑫："芯片占 68%，模组 30%"（合 98%）；澜起："内存接口芯片是公司的绝对主营，营收占比超过 98%"。

   **这一步做完，第五节的三分法和第七节的竞对对照才知道该覆盖谁。** 不做的后果是
   把同等篇幅分给占收入 1% 的业务——那不是全面，是没有取舍。

2. **股权穿透读信号**：
   - 实控人是谁、什么背景、持股链条。
   - 战投是谁、为什么引进？**产业资本入股当第三方背书读**（中控："下游巨头中石化资本、中核基金入股，说明已具备较强竞争力"）。
   - **体外资产**：实控人在上市公司之外还控制什么？（中控褚建体外的 SUPOS；美的何氏家族体外的美的置业、会通新材料）——这是从"人"出发的追踪，年报关联交易附注里挖。

3. **高管读信号**：
   - 有没有产业相关性？有没有人**来自竞争对手**（石基的金凯文/赖德源来自 MICROS = 加分项）？
   - 团队背景是否同源（开立高管都来自汕头超声）？纯内生 vs 空降拼盘。
   - 薪酬水平说明什么（开立"老板薪酬 90 万偏低"；美的事业群总裁薪酬超董事长 = 激励向一线倾斜）。
   - 接班/继任窗口（董事会换届日、有无继任梯队文字）。

4. **股权激励方案当"管理层的自我预期"读**（固定项，必查）：

   激励方案是管理层在信息最充分的位置上，为了拿到股票、经董事会审议、写进公告的**自定目标**。它比任何券商预测都更接近内部人的真实预期。

   要挖四件事：
   - **考核指标是什么、口径的准确定义**。"扣非净利润" / "剔除股份支付费用后的净利润" / "归母净利润" / 某条子业务线的收入——名字接近、含义不同。**必须抄原文定义**，实测这里极易张冠李戴。
   - **历次归属期的达成情况**。连续未达成是很强的负面信号；实测有公司三个归属期全部落空（连 80% 系数的触发值都没摸到）。
   - **基数选在哪一年**。**把基数放在利润塌陷的那一年，然后考核"从坑底涨多少"，是最常见的软化手法。**
   - **是否更换过考核指标**。换指标通常意味着自我预期重置——但要公平：把新方案的**终档目标折算成绝对金额**再判断。实测有公司近端档位低到必然达成，终档却是"五年爬回历史峰值"，只说前一半是不诚实的。

   **"低业绩触发值的激励"是一个复发模式**：澜起（2021）与开立（2026）两只完全不同行业的票都出现过，后者还被媒体点名诟病。这不该靠运气发现。

   **最后做一次对照**：把方案目标折算成利润额，和券商一致预期摆在一起。两者出现系统性差距时，这个差距本身就是判断依据（实测：公司自设目标比卖方共识低 28%）。此项需与竞争 lens 的"共识修正史"交叉。

## 输出契约

先把完整发现写到 `reports/{SYMBOL}_thesis_{报告日}/findings/尽调.md`，再返回：

```
## 发现（事实，带出处）
## 判断要点（bullet，含"不确定"项）
## 建议进档案（假设 / 未决疑问）
```

把股东名单当信号读，不要罗列。查不到的直说。你的返回是数据，不写观点总结散文——那是编排器的活。
