# lens：产业（产品与行业空间 / 商业模式）

> equity-thesis-cn 的产业子 agent 读本文件执行。覆盖第五、六节。
> 定位：自建 TAM、拆商业模式、把模式和财务串成因果链。骨架细节见 `../framework.md` 第五/六节。

## 读什么

- `data/{SYMBOL}/annual_pdf/*.pdf` 的"主营业务/行业情况/经营讨论"章节（Read pages 参数）
- `data/{SYMBOL}/aggregate.json` 的 business；`annual.json` 的 business_segments

## 关键动作

1. **产品谱系矩阵** + 各品类进展与竞争力。分品类，不要笼统。

2. **三段式自建收入模型**（最有价值的动作，能就做，学中控）：

   不要停在"行业空间是多少亿"。往下推一步，落到**公司某年的收入**：

   ```
   行业规模（带复合增速假设） × 渗透率/国产化率爬坡（每年 +X%，写明） × 公司市占率假设
   = 公司目标年收入
   ```

   中控原样：`19 年 DCS 87.4 亿 × 5.5% 复合 × 十年 90% 国产化(每年 4%) → 2023 年 71.5 亿`；工业软件 `MES 市占 4.5%→假设 8%、APC 26%→28% → 公司工业软件收入 10.21 亿`。这个"公司收入"直接喂给第十一节估值的目标年盈利。

   三条纪律：
   - **每段假设写明取值 + 来源**（行业增速引哪份报告、国产化率现状多少）。
   - **敢偏离趋势时给理由**（中控："预计 23% 增速高于 19 年 17% 均值，原因 1)十四五 2)生产控制类软件过去慢未来提速"）。拍高拍低都行，但要说为什么敢。
   - **"国产化率"是一般形式的一个特例**——换成 EV 渗透率、SaaS 渗透率、电动化率同样适用；周期股则换成"产能利用率爬坡"。

   **优先找"供给侧物理约束"变量——它常常比市场规模更硬。**

   当行业规模的第三方口径互相打架、或根本查不到时（软镜行业实测出现过 81.2 亿 vs 393 亿、差近 5 倍的两个口径），不要硬凑一个 top-down 模型，**改去找那个真正卡住需求兑现的物理变量**：

   > 奥林巴斯的调研显示，目前为止日本有 13 万名内窥镜医生，而中国仅 2.6 万名。

   这一条比任何"软镜市场 XX 亿"都硬——**能做内镜的医生数量直接卡住手术量的上限**，而医生培养周期长、人数可查、增长有物理上限。用它建模：`医生数 × 人均年手术量 × 单台设备年手术承载量 → 设备保有量需求`。

   其他行业的同构变量：
   - 医疗设备 → 有资质的操作医师数、装机医院数、内镜中心数
   - 半导体设备 → 晶圆厂在建产线数、洁净室面积
   - 工程机械 → 施工许可面积、开工小时数
   - SaaS → 目标行业的企业数 × 可触达比例

   **判据**：这个变量能不能被少数几个可查的数字确定，且它的增长有没有物理上限。两个都满足，就用它替代 top-down 的市场规模。

   行业规模本身尽量两套口径交叉验证（石基：品牌房间数×年费 vs 高端房间数×月费；美的机器人：IFR 安装量 vs 世界机器人大会销量，差 2.4% 互证），并**给数据分可信度层级**：双口径互证最硬、公司自陈可校验量级中等、无独立数字最弱——别把三档当同一回事。

3. **单价与销量的拆解**（能拆就必须拆）：

   把主力产品的**单价序列**逐年拉出来，与毛利率并排看。澜起那份的做法：

   | | 2016 | 2017 | 2018 | 2019 | 2020 |
   |---|---|---|---|---|---|
   | 内存接口芯片单价（元）| 15.39 | 17.44 | 18.14 | 21.33 | 20.67 |
   | 毛利率 | 63% | 65.84% | 70.82% | 74.82% | 73.22% |

   拆出来之后才能回答"毛利率变化到底是价还是量"。**没有单价，"毛利率下滑"就只是个现象，不是个解释。**

   拆完要找**该品类的定价规律**。澜起总结出三条并用它解释了 2020 年的毛利率下滑：
   （a）技术迭代后新产品售价提高；（b）同一代产品生命周期内单价逐步走低；
   （c）单价前期降得快、后期降得慢，下一代上市后前一代价格基本企稳。

   结论落到"**DDR4 不再有后续子代、等待 DDR5 全面应用，因此存在产品升级空档期**"——
   把一次毛利率下滑解释成了产品世代的结构性空档，而不是竞争恶化。这个判断的性质完全不同。

   **拆不出来就明说。** 年报常只给分产品收入不给量价（实测开立的彩超即如此），
   那就写"量价无法拆分，因此毛利率下滑的价格贡献无法量化"——**不要用"预计主要是降价所致"蒙混过去。**

4. **商业模式矩阵**：经营模式 / 客户粘性 / 盈利模式 / **收入创造公式（写成可拆的乘式：出货量×单价、房间数×年费）** / 上下游结算 / 成本结构。

5. **模式定性 + 串因果链**（模式判断孤立地说没价值）：
   - 允许难听（中控："这就是投资者最不喜欢的项目制模式"）。
   - **和财务问题串成一条链**：ToB 进度法确认收入 → 合同资产/质保金应收沉淀 → 现金流滞后于利润（这条正是美的报告里连起财务、竞争两个子 agent 的关键）。

## 行业注意

- 周期股：行业空间看的是**产能与需求的周期位置**，不是线性增长的 TAM。
- 亏损/次新：TAM 常是想象空间，重点标注"公司现规模 vs 天花板"的倍数，别被大 TAM 带跑。
