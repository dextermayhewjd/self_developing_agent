# 可比性判定（三层）

> `peer-comparability` workflow 里三层判定 agent 的方法论文件。
> 判的是「这个候选跟标的可不可比」，不是「这个候选好不好」。

## 为什么有这份文件

2026-08-27 首次实跑（钨）时，agent 判得很准——翔鹭钨业被判「不可比」，用的是
「原材料占营业成本 90.13%」「采矿权账面仅占总资产 1.47% 且已全额抵押」
「全文无折耗/产量法/剥采比」；章源钨业被判「部分可比」，用的是
「采矿权按年限平均法摊销而非产量法折耗」「分产品收入无钨精矿一行」。

**这些判据一条都不在 prompt 里，是模型自带知识凑出来的。**

这次凑对了。但换一个原型（判「这家是不是真靠息差」）它会不会同样凑出来、凑得一样好，
没有任何保证。**判据不落盘，就等于每次都靠现场发挥**——这与「让 agent 临场自定口径」
是同一个毛病。这份文件把判据固化下来，并给出让它继续生长的机制。

---

## 第一层 · 品种

**问的是**：它产不产这个东西。

读主营描述即可。判据简单，但有一个坑：**产业链上下游都会提到这个品种**。
「钨」在矿企、冶炼商、硬质合金厂、矿山装备厂的主营描述里都会出现。
第一层只筛掉完全不沾边的（浩通科技做贵金属回收，产品含**铼**酸铵——铼 Re ≠ 钨 W，
常因「钨铼合金」被误连），沾边的一律放进第二层，**不要在第一层做业务性质判断**。

---

## 第二层 · 业务性质（本文件的重心）

**问的是**：把本原型的 `归属判据` 反过来套在候选身上，**它是不是也属于这个原型**。

⚠️ **同品种 ≠ 同原型。** 一家公司可以产这个品种，而它的资产是加工产能不是本原型
要求的那类资产。翔鹭产钨，但它是「周期加工型」。

### 通用判法：把归属判据的每个要件，落成年报里可查的痕迹

归属判据是一句话，不能直接查。做法是**逐个要件找会计痕迹**：

```
耗竭资源型 · 归属判据「主要资产有可枯竭的储量，产出为同质大宗商品，售价外生」
  要件一「主要资产是可枯竭储量」 → 查：该类资产占总资产比、折耗政策
  要件二「产出为同质大宗商品」   → 查：分产品收入有无该品种独立行
  要件三「售价外生」             → 查：定价机制表述、是否挂第三方报价
```

**每个要件都要给出可回溯的出处**（页码/章节/原文片段）。给不出出处的判定不成立。

### 已验证信号库（会计指纹，跨行业通用）

这些信号已在实跑中验证有效，**优先使用**：

| 信号 | 读法 | 实证 |
|---|---|---|
| **折耗 / 摊销政策** | 产量法（UoP）= 资产随开采耗竭，真持有该类资产；年限平均法/直线法 = 只是一项权利，多半是加工商 | 章源采矿权按年限平均法（P129）；03858/EQR/G6M 全部 UoP |
| **原材料占营业成本比** | >85% 基本可判为买料加工 | 翔鹭 90.13%、中钨高新 85.86%、章源 92.40% |
| **该类资产占总资产比** | 占比极低说明它不是价值底座 | 翔鹭采矿权 1.47% 且全额抵押；章源 3.3% |
| **分产品收入有无该品种独立行** | 没有独立行 → 它不卖这个东西（自用或根本不产） | 章源分产品收入无钨精矿一行 |
| **分部披露豁免** | 援引单一分部豁免 → 该业务未独立核算，拆不出来 | 章源 P203 援引 CAS 35 |
| **自给率** | 自产量 ÷ 加工投料量。极低 → 矿只是配料来源 | 章源自产 3,691 吨 vs 粉末产量 20,019 吨 = 15–17% |
| **定价机制表述** | 「售价随原料价变动相应调整」= 赚加工价差，**非售价外生** | 翔鹭 p.25 原文 |
| **专项计提规模** | 复垦/修复基金计提额与资产规模不匹配 → 微型资产 | 翔鹭生态修复基金本期仅 16 万元 |

### 反面判据（这些**不算**证据）

- **有储量数字 ≠ 是矿企。** 章源明确披露「钨(WO3)保有资源量 7.41 万吨」，但自给率只有
  15–17%、采矿权仅占总资产 3.3%——**它是加工商，矿只是配料来源**。
  （这条是探针阶段栽过的跟头：看到储量数字就判可比，正是本系统要消灭的那类错误。）
- **行业地位描述 ≠ 资产性质。** 「全球最大单体在产钨矿山」（中钨高新 p.8）说的是它管的矿，
  与它自己的资产结构和收入构成是两回事——该公司加工品收入占 61.51%。
- **引用行业总量数据 ≠ 自有资源。** 年报里出现「全球钨储量 470 万吨（USGS）」是行业背景，
  不是这家公司的储量。翔鹭、中钨高新都只有这一种"储量数字"。

### 判定档位

- `pass` —— 归属判据各要件均有可查证痕迹支持
- `partial` —— 是同类资产但关键特征弱（有矿但矿只占小头、有该业务但未独立核算）
- `fail` —— **原型错配**，它属于另一个原型（要写明属于哪一个）

## 第三层 · 披露制度

**问的是**：它所处的披露制度，是否强制披露本原型的必比口径。

先读 `data/_peers/_regimes.json`。没有该口径的条目就自己判并**写回该文件**。

**两种「拿不到」必须分开**：

- **制度性不可得** —— 该市场/制度根本不强制这条口径。换样本才有用，抠得再细也没用。
  例：中国企业会计准则不强制分类储量表/储量 NPV/单位现金成本/设计产能/自产率，
  A 股矿企因此系统性出局。
- **个案未披露** —— 制度上强制或普遍披露，但这一家没给。换一家可能就有。
  例：G6M 的 NPV 具体数值本轮未取到，但 ASX 制度下可补。

**还有一种更根本的不可得，要单独识别**：口径本身要求的东西不由任何披露制度产出。
「C1/AISC 在全球成本曲线的**分位**」就是——成本曲线是 Wood Mackenzie / CRU 的付费私有
数据库，**没有任何一家公司能披露"分位"**，换一百家样本也拿不到。这类要在台账里写明
「该口径在方法论上不可回溯，应改为与已披露同业的绝对值逐点对照」。

## 输出要求

除 schema 要求的字段外，**必须报告你用了哪些信号、每个信号的来源**：

```
used_signals: [
  { signal: "原材料占营业成本比 90.13%", source: "library", conclusion_weight: "决定性" },
  { signal: "生态修复基金计提仅 16 万元", source: "improvised", conclusion_weight: "辅助" }
]
```

`source` 取 `library`（本文件已有）或 `improvised`（你现编的）。

**这不是记账，是这套系统自我改进的唯一入口**：现编且起了决定性作用的信号，是下一轮
该被固化进信号库的候选；而库里有却没能命中的信号，说明它对这个原型不适用，该标注适用范围。
如实报告，不要为了显得"用了方法论"而把现编的说成库里的。

## 与原型表的关系

原型表 `valuation_archetypes.md` 每段的 `归属信号` 字段是**本原型专属**的可查证信号；
本文件的信号库是**跨原型通用**的会计指纹。两者配合：

- 先看原型表的 `归属信号`（专属，更准）
- 再用本文件的通用指纹补充
- `归属信号` 标着「尚未确定」的原型，第二层判定是模型自由发挥——**台账里要如实标注这一点**，
  不要让读者以为那一格的判定与钨这种已验证过的原型同等可靠。
