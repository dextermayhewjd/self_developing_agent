# 十二节骨架

> 来源：次新股小组内部研究框架（石基信息 / 乐鑫科技 / 中控技术 / 开立医疗 / 澜起科技 五份底稿）。
> 每节都走 SKILL.md 的三段式：**详细资料/数据 → 细节补充 → 观点总结**。

---

## 开篇三条原则（先读这里）

### 一、下面的问句是菜单，不是清单

各节列出的固定问句（财务五问、排雷九项、竞争六问、战略二问……）是**备选池**。

**做法**：每节挑 2–4 个与这家公司的判断真正相关的问题深答，其余明确跳过。跳过的在该节「细节补充」里用一行交代：`跳过：CR3 变化（行业集中度对本案判断不构成分歧点）`。

这不是偷懒，是原框架本来的用法。石基那份底稿里就有问题原样留着没答、募投项目数据段直接空着——**留白是这套框架的特性**。三十个问题全答一遍，得到的是一份更长的数据稿，不是判断稿。

判断标准：这个问题的答案会不会改变我的结论？不会就跳过。

### 二、长度不设上限，但要求配比

**不限总字数。** 判断稿写到三四万字是可以的——人工底稿也有 23 页的。

但要求**观点总结段不被数据段淹没**：全文「观点总结」三段合计的字数，应当不少于「详细资料/数据」三段合计的三分之一。数据段可以厚，观点段必须跟着厚。

超长时砍数据段，不砍观点总结——观点总结是这份稿子存在的理由，纯数据在 `equity-report-cn` 的底稿里已经有一份了。

---

**不要平均用力**——哪一节的判断最难下，哪一节就该用满预算；判断显而易见的节写 200 字也可以。

### 三、按行业调整重心（第一步就判本票属于哪类）

12 节骨架不变，但**各节的强调和估值方法随行业变**。落笔前先根据 `business` 字段判类，编排器在派子 agent 时把类别一并告知：

| 行业类型 | 加重的节 / 必加分析 | 估值方法（详见十一节） |
|---|---|---|
| 银行/保险/券商 | 资本充足率、不良率、拨备；股权结构（国资） | P/B × ROE |
| 半导体/重资本制造 | Capex 强度、折旧、产能利用率、国产替代 | P/B–ROE、EV/EBITDA |
| **周期股（化工/钢铁/煤炭/有色）** | 商品价位置、库存、产能、成本曲线 | 穿越周期 P/B、中周期盈利 |
| 白酒/消费 | 渠道库存、批价、品牌力 | PE + 股息率 |
| 医药/创新药 | 管线进度、专利期、临床数据 | 管线 NPV、PS |
| 互联网/软件 | 获客、留存、Rule of 40、ToB 进度法确认收入 | PS、EV-Sales |
| 亏损/次新未盈利 | 现金跑道、烧钱速度、收入验证 | PS + 现金跑道 |
| 房地产/建筑 | 拿地、去化、现金流、隐性负债 | NAV、P/B |

判类之后，财务排雷的阈值也随之变（见 `financial-redflags-cn` 的行业变体表）。**不判类就套成长股模板，是这套框架最容易翻车的地方。**

## 一、公司简介

**写什么**：主营 + 行业地位 + 收入结构拆分（分业务占比）+ 所处产业阶段。

**必须做的动作**：按发展阶段分段，而不是流水账。例：中控技术分"2006 年前 / 2007–2015 / 2016 至今"三段，每段一句话说清楚它当时是家什么公司。

**疑惑清单不在本节输出，在第四节末尾。** 见下方第四节与 SKILL.md 步骤 2——疑惑要从财务数字里逼出来，不是从主营业务描述里憋出来。

---

## 二、股权架构

**写什么**：股权穿透（实控人 → 上市公司 → 主要子公司）+ 战投。

**观点总结要回答**：
- 实控人是谁、什么背景？
- 战投是谁、为什么引进、说明了什么？

产业资本入股要当信号读。中控技术那份把中石化资本 4.95%、中核基金 3.00% 读成"下游巨头型客户的入股能在一定程度上说明公司在行业中已具备较强竞争力"——**这是把股东名单当第三方背书来用**，不是罗列。

同时留意**体外资产**：实控人在上市公司之外还控制什么？中控技术的褚建体外另有 SUPOS 工业操作系统，直接影响投资判断。

---

## 三、高管信息

**写什么**：姓名/职务/任职起始/学历/出生年份/简历。

**观点总结要回答**：
- 履历里有没有**产业相关性**？
- 有没有人**来自竞争对手**？（石基的赖德源、金凯文均来自 MICROS，判为加分项）
- 团队背景是否同源？（开立前五位高管都来自汕头超声，带超声诊断基因）
- 薪酬水平说明什么？（开立"老板薪酬 90 万一年，水平在上市公司行业明显偏低"）

---

## 四、财务全景表

取近三个完整年度 + 最新一期季报（能取到更长就取更长）。指标覆盖：增长与费用 / 回报与结构 / 营运与现金三组。异常项标红。

### 固定五问

1. **收入和净利润增速有没有关键跳跃点？背后的原因是什么？**
2. **使用财务排雷单扫描过后是否发现异常？**（清单见下）
3. **收入和净利润增速是否有明显差距？这差距来自哪里？**
4. **毛利率变化的原因来自哪里？和竞争对手相比是高是低？**
5. 个股定制题（本只股票财务上最反常的那件事）

### 财务排雷单（九项，逐项走查）

| 项 | 看什么 |
|---|---|
| 毛利率 | 趋势、与同业差、分产品差异 |
| 其他应收款 | 是否藏了关联方占款 |
| 其他应付款 | 是否藏了未决义务 |
| 预付款项 | 是否异常放大 |
| 固定资产 | 占总资产比、是否与产能匹配 |
| 在建工程 | 转固节奏、是否为办公楼等非生产性投入 |
| 净现比 | 经营现金流 / 净利润 |
| 大存大贷 | 高货币资金 + 高有息负债并存，算实际收益率 |
| 商誉占比 | 占总资产比、是否已减值、业绩承诺兑现情况 |

走查完给结论，哪怕结论是"综上，未发现明显异常"（乐鑫）。**发现问题要点名**——中控技术"最大的问题就是应收账款。项目类公司的通病。"

### 本节末尾：输出疑惑清单（2–4 条）

**看完上面的全景表和五问之后，在这里立疑**——这是人工底稿的真实顺序。开立那份原文就长这样：

> 一开始看开立就有 2 个问题：
> 1. 内窥镜是否可以再创造一个开立的规模？
> 2. 彩超业务是否可以恢复正常增速 15% 左右？

**两条，都是决策形状的。** 判据见 SKILL.md 步骤 2：这个问题的答案会不会直接改变我买不买。
"利润为什么塌了""毛利率去哪了"这类是**排查项**，写进给子 agent 的派活 prompt，不占疑惑清单的位置。

### 口径重算

跨公司对标费用率前，先检查分部是否可比。石基那份的做法：

> 财报上研发费用率是 8%，我认为这个数据的统计口径不准确，计算公式改为
> 研发费用率 =（费用化研发 + 资本化研发）/（总营收 − 硬件营收），
> 按这个公式 2018 年约 21%，2019 年约 27%。

重算了就在「细节补充」里写明原公式、新公式、差异，以及为什么新的更合适。

## 五、产品与行业空间

**写什么**：产品谱系（分品类矩阵表）→ 产品进展 → 竞争力 → 行业空间。

**行业空间尽量做两套独立口径交叉验证**。石基那份：

- 口径一：品牌酒店房间 910 万间 × 每间每年 50–200 美元（产业调研价）→ 全球约 500–600 亿人民币
- 口径二：高端房间 479 万间 × 15 美元/月 → 约 58.5 亿人民币
- 结论："无论哪一个统计口径对石基来说都是现有条件下的增量。"

**自建 TAM 时每个假设参数都要写明取值和理由。** 中控技术的写法值得抄：

> 19 年国内 DCS 市场规模 87.4 亿，我们假设未来五年复合增速 5%-6%（取平均值 5.5%），
> 19 年大约 50% DCS 为非国产，假设十年完成 90% 国产化（平均每年提升 4%），
> 预计 2023 年 DCS 国产化市场将达 71.5 亿。

假设可以拍，但必须**拍在明处**。

## 六、商业模式

**写什么**：分品类商业模式矩阵 + 前五大客户 + 前五大供应商。

矩阵行项（开立/澜起共用）：经营模式 / 客户粘性 / 盈利模式 / 销售方式 / **收入创造公式** / 供应商结算 / 客户结算 / 成本结构 / 收入区域构成。

「收入创造公式」要写成可拆的乘式（单价 × 销量、房间数 × 每间年费）,不是描述。

**观点总结要对商业模式定性，允许难听**：

> 这个就是投资者最不喜欢的项目制模式，工程周期长，定制化的工作很多，客户强势，
> 收款周期长，还需要不断的提供售后服务。目前看短期是没有变化的可能的。

并且要**和第四节的财务问题串成因果链**——项目制 → 应收账款高 → 现金周期 453 天。孤立地说"商业模式一般"没有价值。

---

## 七、竞争格局

全文最重的一节。

### 固定六问

1. **公司的市场份额是多少？竞争地位排名第几？**
2. **竞争对手情况**——做逐项对照表：外资/本土、是否上市、直接竞争业务、市占率、知名客户、产品特点、竞争优势、财务数据。竞对未披露的数据可以**反算**，但要标注方法（"按市占率反算""按 2014 年报表净利率推算"）。
3. **行业集中度如何？CR3 合计多少？最近 5 年怎么变化的？**
4. **关键成功要素是什么？**（候选：牌照 / 低成本 / 研发 / 营销 / 渠道 / 自然资源）
5. **公司相比竞对的优势体现在哪里？**
6. **国外有没有可以对标的公司？从国际经验看，这个行业是否出现过大市值企业？**

第 6 问常常最有用——澜起用"IDT 曾以 8500 万美元收购新涛，相当于当时新浪搜狐市值总和"来锚定行业的历史天花板；中控用西门子/艾默生/施耐德"近两年均做了大规模软件厂商收购"反推中控的演进方向。

### 份额变动要归因到事件

不要只给份额曲线。澜起那份把 Rambus 2020 年份额跳升归因到具体人事：

> 2019 年 8 月，IDT 负责内存接口芯片业务的副总裁 Sean Fan 离职后加入 Rambus，
> 对 IDT 原副总裁有粘性的客户也随其转向 Rambus。

## 八、募投项目 / 重大资本开支

**写什么**：募资去向、大额投资、并购标的。

**观点总结要回答**：是否围绕主业？跨界的成功概率如何？

允许直接批评历史决策：

> 我都不明白石基是一个软件服务商去搞医疗器械销售，这是一个相差很远的行业，
> 成功的概率很低，好消息是 2017 年后医疗器械就没有了。

## 九、公司发展目标及战略规划

### 固定二问

1. **公司是否已经制定了 5 年以上的长期目标和战略规划？**
2. **企业将通过什么样的方法和步骤来实现这个目标？**

### 增长路径分类（逐条判断公司走哪条）

| 路径 | 定义 |
|---|---|
| 外延收购 | 同业务收购 or 跨界收购 |
| 内生—横向拓展 | 开同样的店，复制到各地 |
| 内生—相关多元化 | 不同业务但同属一个行业、有联系（如品类扩张） |
| 纵向一体化 | 往上下游发展 |
| 国际化 | 走出去 |

对国际化尤其要下判断，且可以判它是错的。石基那份直接说"我认为是正确的……假如能上线主流的高端酒店，再对低星级和经济型酒店进行降维打击才是正确的套路。"

## 十、未来业绩驱动因素

列"驱动因素一 / 二 / 三"，每条一句话。

**固定问句**：除了产能提升以外，以上几种路径中，公司未来实现增长最大可能会采用哪一种？为什么？

**设计一个领先指标。** 这是本节最有价值的动作——找一个比业绩更早出现的验证信号。石基那份：

> 2018 年起餐饮管理系统收入比 2017 年下降了，推断是收入模式从"软件授权+维护合同"
> 转成 SaaS 年费/月费，这是一个很好的信号。虽然餐饮分项收入占比很小，
> **但这是酒店 PMS 系统云化能否成功的排头兵。**

一个分部收入的下降被读成转型成功的先行证据——机器不会这么读，但这正是判断稿的价值所在。

**Alpha / Beta 切分**：公司的增长里，多少来自自身能力，多少来自行业景气？乐鑫那份的结论是"公司主动地抓取 alpha 的能力有限，更依赖行业 beta 的到来"，并用产品收入结构证明 ESP32 新品对增长的贡献远小于直觉。

## 十一、估值、赔率、概率分析

### 先选估值方法（按盈利状态分叉，不能一套打天下）

**这是泛化的关键。** 成长股的"行业规模×市占率×净利率"框架在周期股/亏损股/银行上会崩。先判本票属于哪类，再选方法：

| 本票状态 | 首选估值 | 为什么，怎么做 |
|---|---|---|
| 成长/正常盈利 | 前瞻 PE 三情景 | 行业规模 × 市占率 × 净利率 → 目标年净利 × 倍数 → 市值 |
| **周期股（底/顶）** | 穿越周期 P/B–ROE 或中周期盈利 | 当期 PE 失效（底部 PE 虚高、顶部 PE 虚低）。用**正常化中周期盈利**或 P/B×合理 ROE 反推。明确写"单 PE 在此误导" |
| **亏损/微利** | PS / EV-Sales + 现金跑道 | 无正 EPS，PE 无意义。看收入倍数 + 账上现金能烧几年（现金/年经营净流出） |
| 银行/保险/券商 | P/B × ROE | 叠加资本充足率、不良率；不用毛利率 |
| 重资产/公用事业 | EV/EBITDA、股息率 | 折旧口径差异大，PE 不可比 |
| 消费/品牌 | PE + 股息率 | 叠加渠道库存、批价 |

选定后做**三情景**（乐观/中性/悲观），三层假设都显式。目标年一般 3–5 年后，说明为什么选这个年份（澜起："很多重要节点大概率将在未来 5 年内充分演绎"；周期股可选"下一轮景气中点"）。

### 输出形态

- **市值区间**，不是股价目标位。
- **赔率区间**，精度到十位数（"赔率在 -20% 至 440%"）。
- **"几年一倍"**——把赔率折成时间。开立那份的写法：
  > 假设今年增长停滞，那么时间将需要延后一年才有一倍的赔率。

  这比单给一个赔率区间更能指导仓位：同样是 +100%，三年翻倍和六年翻倍是两笔完全不同的投资。
  中性情景下给一句"按当前假设，约 N 年一倍；若<某条件>不兑现，顺延 M 年"。
- **概率**：没把握就明写"概率我就不敢猜了"。
- 与**当前市值**对照，给一句结论（澜起："公司当前市值 610 亿，对我而言尚不存在明显的投资价值"）。
- **给出行动触发条件**。判断稿的出口是"进不进池子、盯哪个变量"，那就要说清什么情况下会改变行动。
  开立那份写得很直白：
  > 如果公司 2020 年业务扑街反而有更好的赔率来布局开立医疗。

  坏消息可以是买点——但必须**事先**写明是哪种坏消息、跌到什么位置。事后再说就是马后炮。

### 允许并鼓励暴露能力圈边界

> 这使得我只能拍出一个非常宽泛的价值范围（宽泛到我个人认为完全缺乏参考意义……），
> 再加上对公司的竞争优势理解很浅，我个人倾向于给到保守到中性价值区间更高的概率，
> 从而保留足够的安全边际。

这段话的信息量比一个假精确的目标价高得多。

## 十二、评分

### 五维打分（各 1–5 分）

| 维度 | 打分要点 |
|---|---|
| 商业模式 | 是否轻资产、现金流前置、客户粘性 |
| 竞争格局 | 玩家是否清晰、份额是否稳固 |
| 赛道 | 行业空间与增速 |
| 稀缺性 | A 股是否有替代标的 |
| 财务 | 报表是否干净、排雷单结果 |

每项后面跟一句**说明**，不能只有数字：

> 财务：B。资产和负债结构比较干净，但是账面资金太多了。

### 字母评级

**先算五维均分，再按固定档位映射到字母。** 开立那份人工底稿的做法就是这样——"得分 3.4……评级：B"。

| 五维均分 | 字母 |
|---|---|
| ≥ 4.0 | **A** |
| 3.5 – 3.9 | **B+** |
| 3.0 – 3.4 | **B** |
| 2.5 – 2.9 | **B−** |
| < 2.5 | **C** |

**为什么要固化映射**：不固化就等于每期重掷一次骰子——同一组评分这期给 B、下期给 B−，读的人无法判断是判断变了还是手抖了。映射固定之后，**字母的变化必然对应某一维分数的变化**，而分数变化必须在正文里给理由。这是档案能跨期比较的前提。

允许偏离一档，但**必须写明理由**（例："均分 3.2 对应 B，我压到 B− ，因为财务那 2 分扣在现金流这个要害上，不是普通的均值贡献"）。偏离超过一档说明评分本身有问题，回去改评分。

参考基准：`《次新股选股范式》`《财务完美五要素》（初善君）——这两份文档不在本仓库，若用户提供则读取，否则按上表自行判断并在正文说明评级依据。

### 收敛到一个决定性变量

全文最后收敛到一个可观察、可证伪的二元问题：

> 我认为公司的基本盘是稳的，目前估值不高主要是**国际大酒店集团是否会上线石基 PMS 的确定性问题**。
> 占据了国际高端酒店的份额，就取得行业的话语权。**成功与否就看这一步了。**

这个变量要写进档案，作为下期首先核对的对象。

### 决定性变量必须写成正反两栏

**只说"这个变量决定一切"是不够的，要把两边的理由都列出来。** 开立那份底稿对"内窥镜能否再造一个开立"给了四条利好和四条难点，两栏对摆：

| 利好（原文提炼）| 难点（原文提炼）|
|---|---|
| 国内软镜占比 19% vs 国际 28%，渗透率有空间 | 核心光学技术突破难，需要很长时间积累 |
| CMOS 技术进步绕开了日企的 CCD 壁垒 | 学术推广需要时间 |
| 本土化售后响应比奥林巴斯有优势 | 医院渠道垄断与医生使用粘性还需突破 |
| 分级诊疗与按项目付费利好高性价比国产 | 内镜执照医师培养漫长（日本 13 万人 vs 中国 2.6 万人）|

**这张表的价值在于它让判断可被后续证伪**：下一期回来看，是利好那栏在兑现，还是难点那栏在应验。只写一句"看好内镜"的话，下期无从核对。

写完两栏再给倾向，并说明**为什么这一栏压过另一栏**。允许写"两栏势均力敌，所以我不出手"——那也是一个明确的结论。
