# 财务排雷单（A 股财务体检）

## 这份 skill 做什么

对一只 A 股做**财务体检**，产出三样：
1. **财务全景表**——21 指标 × 近三年+最新季度，异常项标红。
2. **九项排雷单**——逐项走查，每项一句话结论（哪怕结论是"未见异常"）。
3. **杜邦拆解 + 归因**——ROE 拆成净利率 × 周转 × 杠杆，找增速跳跃点的成因。

来源：次新股小组《财务排雷单》——一份跨公司复用的命名方法论，同一套九项扫描用在所有票上。

**核心原则**：指标是围绕"我怀疑什么"选的，不是全量堆砌。发现问题要**点名**（"最大的问题就是应收账款，项目类公司的通病"），不要写成中性描述。查不到的直说"我没查到"，不要填满。

## 何时用

- 独立：只想给某票做财务尽调 / 排雷。
- 作 `equity-thesis-cn` 的财务子 agent（第四节）：读本 skill、走流程、把发现写进 run 文件夹的 `findings/财务排雷.md`。

## 输入

```
data/{SYMBOL}/aggregate.json      # financials_annual / financials_quarterly
data/{SYMBOL}/annual_pdf/*.pdf    # 三表 + 附注（用 Read pages 参数按需读）
data/{SYMBOL}/annual.json         # 关键段落
```

## 财务全景表（21 指标，三组）

| 组 | 指标 |
|---|---|
| 增长与费用 | 营收增速、销售毛利率、销售/管理/研发/财务费用率、研发占（营收−硬件营收）比 |
| 回报与结构 | 归母增速、扣非增速、ROE、ROA、权益乘数、净利率、资产负债率 |
| 营运与现金 | 应收/应付/存货周转天数、现金周期、销售收现比、经营现金流净额/净利润（净现比） |

取近三个完整年度 + 最新季报，能取更长就更长。异常项（负值、突变、远离同业）标出来。

## 九项排雷单（逐项走查 + 行业阈值）

每一项：先看数、再判"正常/警讯"，**阈值随行业变**。

| 项 | 看什么 | 正常 vs 警讯（含行业变体） |
|---|---|---|
| 毛利率 | 趋势、与同业差、分产品差异 | 跨公司对标前先查分部是否可比；不可比就**重算**（如研发费用率剔除硬件营收）。骤降查是量价哪一头 |
| 其他应收款 | 是否藏关联方占款 | 占总资产 >5% 且账龄长 = 警讯；押金/员工借款性质则无妨 |
| 其他应付款 | 是否藏未决义务 | 突增查明细（股权转让款/返利/押金） |
| 预付款项 | 是否异常放大 | 对单一供应商大额预付 + 账龄长 = 警讯（利益输送嫌疑） |
| 固定资产 | 占比、与产能匹配 | 扩产期高是常态；稳态突增查是否买楼等非生产性 |
| 在建工程 | 转固节奏 | 长期挂账不转固 = 警讯（藏费用/推迟折旧）；CIP/固资比走低是健康 |
| 净现比 | OCF/净利润 | <1 且持续 = 利润含金量低；周期股底部单季可为负属正常 |
| 大存大贷 | 高货币+高有息负债并存 | **算实际利差**。多元集团资金归集可能正常；单一主业大存大贷 = 警讯 |
| 商誉占比 | 占总资产/净资产比、减值测试假设 | 并购型科技高商誉是常态（看减值假设是否逐年下修）；公用事业/制造高商誉 = 警讯 |

走查完给总结，哪怕是"综上，未发现明显异常"。

## 杜邦拆解（ROE 归因，必做）

`ROE = 净利率 × 总资产周转率 × 权益乘数`

用它回答"ROE 变动是哪一项在拖"。**常见陷阱**：ROE 下滑常被误读成盈利恶化，但可能是权益乘数下降（如再融资做大净资产）而净利率反升——这是良性稀释，不是警讯。拆开才知道。

## 行业变体（阈值不是一套）

| 行业 | 排雷重点 |
|---|---|
| 周期股（化工/钢铁/煤炭） | 穿越周期看毛利率区间；底部净现比可为负；主动补库存不必然是坏事 |
| 银行/保险/券商 | 关注不良率、资本充足率、拨备覆盖率，而非毛利率 |
| ToB/项目制 | 应收/合同资产高是模式使然，看账龄与减值；进度法确认收入 → 现金流滞后于利润 |
| 并购型科技 | 高商誉常态，盯减值测试假设是否逐年下修、被并购标的业绩承诺兑现 |
| 重资产/公用事业 | 折旧政策、在建转固、资本开支强度 |
| 消费/快消 | 应收应该低（现结），高就是警讯；预收/合同负债是需求前瞻信号 |

## 输出格式（给编排器的数据，非成稿散文）

作 thesis 子 agent 时，先把完整发现写到 `reports/{SYMBOL}_thesis_{报告日}/findings/财务排雷.md`，再返回：

```
## 发现（事实，带出处）
- <事实>（来源：年报 p.X / aggregate 字段）

## 判断要点（bullet，不写成段）
- <一句话判断> —— 依据：<哪条发现>
- 不确定：<明确说不知道的>

## 建议进档案
- 假设：<可被后续证伪的陈述>
- 未决疑问：<答不出来的>
```

判断要点里**必须有"不确定"项**。不要写引言、不要写观点总结散文——那是编排器的活。

## worked example（000333 的两个真实动作）

**ROE 拆解破误读**：美的 ROE 五年 24.1%→19.7%，看着像盈利恶化。杜邦拆开：净利率 8.50%→9.75%（升）、ROA 走平、权益乘数 2.57x→2.16x（降）。降因是 H 股募资 321 亿一次性做大净资产——**是良性稀释，不是警讯**。这就是杜邦必做的理由。

**大存大贷看穿"搬家"**：货币资金 -39.3% 看着像资金流失，但同期固收类理财 +43.3%——是现金搬到理财科目，非流失。同时短借 +41.6% 但总有息负债 -22.3%，是债务置换。**每一个"异动"都要追到底再下结论**。
