# 推理协议（合成顺序与自检）

## 写作顺序（不可改）

LLM 在按模板填充时，必须按以下顺序合成，**不能跳步**：

### Step A — 读数据并做"数据点清单"
在落笔任何文字前，先列出：
- 当前价、市值、估值倍数（PE/PB/PS）
- 5 年营收 / 净利 / 毛利率 / ROE
- 季度营收节奏（8 季单季）
- 最近的研报 EPS 共识（区间 + 中位）；若 `research_coverage != "covered"` 或 `consensus_eps_available`
  为 false，此项记为「无券商覆盖」或「未取得」（措辞见 data_contract.md），情景 EPS 改由历史财务自行推演，
  并在 1.6 注明缺少卖方交叉验证
- 最近 3 条重要公告 / 新闻 / 重组 / 事件——**读正文**：`earnings_call.json` 的 material_contract /
  accounting_change / investment / lockup_release 四类。只看标题会漏掉合同金额这类改变判断的数字
- 最新半年报分产品表（`annual.json` 的 `semiannual`，有则必读）：分部增长来源与年报叙事不一致时以最新一期为准
- 十大股东结构（国资 vs 机构 vs 个人）+ 限售解禁队列（`restricted_release`）
- 交易面：两融余额（`margin_recent`）、龙虎榜（`lhb_recent`）、同期基准指数（`benchmark_index`）

这份清单是后续所有判断的依据。**任何不在清单里的数字不得出现在报告里**。

### Step B — 先写 1.3 可证伪点，再回写 1.1 投资主张
理由：先想"什么会让这个故事破"再写"故事是什么"，避免投资主张被"必胜叙事"裹挟。

### Step C — 估值三套并用（PE-forward + P/B–ROE + P/S 兜底）
- 当 PE(TTM) > 80x 或为负：必须用 P/B–ROE 或 P/S 兜底，不能单 PE 锚定
- 当公司处于周期底/亏损：单 PE 误导，必须做"假设 ROE 修复"的情景化估值
- Base 情景必须两套方法重叠

### Step D — 多空对称
1.7 节多/空各列 ≥3 条，每条必须可被 1.3 节的某个信号证伪/证实。

### Step E — 自检（生成后必跑）
- grep `{{` ——确保没有未替换占位符
- grep `\[L\]` ——计数所有 L 标记的判断；超过 20 条则在末尾加"低置信度判断较多，建议人工 review"
- grep "未取得" ——确认所有缺失项均有显式说明
- 数字一致性：1.5 节的 PE × EPS ≈ 1.6 Base 情景的目标价区间内

## 置信度标记规则

| 标记 | 何时使用 |
|---|---|
| [H] | 直接读自 data JSON 的事实陈述（如"营收 ¥673.2 亿"） |
| [M] | 推理性判断，前提数据可靠（如"周期底部已确认"） |
| [L] | 弱证据 / 需人工 review / 数据来源不全（如"行业地位第 5"，无最新行业报告） |

**默认偏保守**：拿不准时标 M 而非 H；标 L 不丢人，标错 H 会误导用户。

## 拒绝写作的红线

满足任一即向用户报错，**不出报告**：

1. `data/{SYMBOL}/aggregate.json` 不存在；
2. `validate.py` 退出码 ≠ 0；
3. 5 年财务数据少于 3 年；
4. 最新报告期距今超过 18 个月（信息过时）；
5. 公司处于退市风险（ST/*ST）但 SKILL 未明示用户已知情。

## 估值情景的"合理性约束"

- Bear vs Bull 估值倍数差距不超过 3 倍
- Base 情景的 PE 区间宽度不超过 30%（如 20–26x，不是 15–30x）
- 任何情景的目标价区间宽度不超过现价 ±50%

超出以上约束时，应在文字中明示"波动区间宽，反映高度不确定性"，而非无理由扩大区间。

## 行业适配（必须根据 `business` 字段调整）

| 行业关键词 | 估值首选 | 必加章节 |
|---|---|---|
| 银行 / 保险 / 券商 | P/B、P/E、ROA | 资本充足率、不良率 |
| 半导体 / 重资本制造 | P/B-ROE、EV/EBITDA | Capex 强度、折旧 |
| 白酒 / 消费 | P/E、股息率 | 渠道库存、批价 |
| 医药 / 创新药 | 管线 NPV、P/S | 临床进度、专利期 |
| 互联网 / 软件 | P/S、Rule of 40 | 增长 vs 盈利平衡 |
| 房地产 / 建筑 | NAV、P/B | 拿地、现金流 |
| 周期股（钢铁、煤炭、有色） | 穿越周期 P/B、EV/EBITDA | 商品价、库存 |

模板默认是"通用"，自动化时根据 `business` 字段中的关键词调整章节强调。
