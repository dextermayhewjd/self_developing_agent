## 当前判断

一家把 JEDEC 标准话语权变成现金流的公司，基本盘（内存互连芯片）全球第一、格局稳定十二年，质地是 A 档。但 2,660.8 亿元市值（PE(TTM) 104.0x、PS 46.7x、PB 12.8x）已经把"第二曲线基本兑现"的中性情景提前四年买单，中性赔率只剩四年 +15%，下行 −47%、上行 +99%，不对称且方向不利。**A 档公司，当前价格不进池子。**

**决定性变量**：2027 年支持 PCIe 6.0 与第二子代 MRDIMM 的服务器 CPU 平台规模量产之后，澜起能不能把 PCIe 互连的全球份额从 10.9% 推到 15% 以上？

## 估值锚

- **目标年 2029**（DDR5 生命周期走完、PCIe 6.0/CXL 3.x 完成产业导入、MRDIMM 起步、CKD 接近标配）。
  - 建档说明：产业侧提出 2029 对 MRDIMM/CXL 是"过渡年"而非"成熟年"，更能代表第二曲线成熟的是 2031–2032。**采纳方式是在 MRDIMM/CXL 两条线取偏保守的渗透参数，而不是把目标年后推。**
- **PE 倍数：保守 30x / 中性 40x / 乐观 50x**（2026-08-18 建档设定）
  - 依据：澜起自身 2020-06 至今 1,500 个交易日 PE(TTM) 带 = 最低 40.5x / p25 63.6x / 中位 76.5x / p75 97.5x / 最高 151.0x；同业当前 PE(TTM) 聚辰 34.9x、复旦微 53.7x、瑞芯微 61.3x、北方华创 101.1x。
  - **中性 40x** 与 2020 年那份人工底稿用的 40x 一致，也接近澜起六年 PE 最低值 40.5x。
  - **保守 30x 低于澜起历史最低 40.5x**，理由已在正文写明：那个最低值出现在 2022-10、当时市场仍相信 DDR5 红利在前方；保守情景下 2029 年看到的是一家增速回落到十几个点、第二曲线被证伪的公司，不该继续享有周期底部的期权溢价。
- **2029E 归母：保守 47.0 亿 / 中性 76.4 亿 / 乐观 105.8 亿**
- **2029E 市值：1,410 亿 / 3,060 亿 / 5,290 亿**；相对 T-0 2,660.8 亿的赔率 **−47% / +15% / +99%**
- 卖方一致预期（n=29/29/5）：2026E 归母中位 31.5 亿、2027E 39.8 亿、2028E 58.6 亿。**我的中性 2029E 比 2028 年一致预期再高 30%，属偏乐观一档。**
- 自建预测：见 2026-08-18 报告第十一节（三情景已拆到产品线：内存互连 / PCIe 互连 / CXL 互连 / 津逮 / 储备不计入）

## 口径修正

> 这只票特有的、每次都要用的口径陷阱。不记下来每次都会踩。

- **子公司九列宽表（"主要控股参股公司分析"）**：`Montage Technology Holdings Company Limited` 是**注册于开曼的投资控股实体**（年报日后事项称其"澜起开曼"，即持有 XConn 13.075% 的主体），**不是香港实体**；真正的香港实体 `Montage Hong Kong Holdings Company Limited` 未出现在该表中。首轮 findings 在此误标（发现于 2026-08-18）。
- **"实际税率"三年年报全文零命中**，必须自行重算：所得税费用 / 利润总额 = 4.46%(2023) / 5.09%(2024) / 8.23%(2025)。引用时须标"重算"（发现于 2026-08-18）。
- **"2026H1 约 6.5 亿非经常性损益"是机械相减重算值**（归母区间 − 扣非区间，两端都恰好 6.50 亿），**不是公司披露口径**，公司从未点名标的。引用时须标"重算"（发现于 2026-08-18）。
- **股份支付 4.50 亿 vs 3.20 亿不是包含关系**：4.50 亿 = 全员 + 仅权益结算 + 计入资本公积（核心高管 3.40 + 其他员工 1.10）；3.20 亿 = 仅核心高管、权益结算 3.40 与现金结算 SAR 冲回 −0.196 相抵后的当期损益净额，那笔冲回不在 4.50 亿范围内（发现于 2026-08-18）。
- **量价拆解要分期**：2024→2025 才是几乎纯量驱动（ASP +0.25%）；2023→2024 是量价共振（ASP +11.21%）。不要笼统说"三年增长全部来自量"（发现于 2026-08-18）。
- **跨地区比毛利率前必须先剔津逮®**：津逮 100% 境内、毛利率仅 7.42%，是境内外 13.25pp 毛利率差的约 85% 来源；剔除后互连类芯片本身境内外差只有 1.95pp（发现于 2026-08-18）。
- **利润与收入的地理错配是转让定价结构，不是读数错误**：澳门主体扛 98.1% 合并收入（53.51 亿）但营业利润率仅 16.4%、税率 12%；昆山收入不足其两成但营业利润率 83.3%、税率 0%（五年免税期），净利润反而更高（9.39 亿 vs 7.66 亿）（发现于 2026-08-18）。
- **弗若斯特沙利文份额数据的性质**：出自公司 2026-01-30 H 股招股章程委托编制的独立市场研究报告，公司自己在年报脚注做了免责声明；只有 2024 年一个快照，2023/2024 年报中不存在（时点原因，非漏披露）。**这批 TAM 是整份估值里最软的输入，没有第二个独立来源可校验**（发现于 2026-08-18）。
