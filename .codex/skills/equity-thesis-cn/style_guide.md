# 判断稿风格与术语（自含，不依赖其他 skill）

## 语言
- 简体中文。财务术语用 A 股标准译法（归母净利润、扣非净利润、销售毛利率、经营现金流）。
- 英文术语首次出现括注（如"经营现金流（OCF）"）。

## 单位与数字
- 金额：**人民币亿元**（不混用万元/万亿/万美元）。
- 股价：**元**，前缀 `¥`；市净率/EPS 两位小数；股价两位小数。
- 比率：百分比带 `%`，一位小数（YoY/QoQ/CAGR）。
- 倍数：`x`（如 `13.5x`）。市值：亿元一位小数。大额不用科学计数法。

## 时间与价格口径
- **CY = 日历年**（A 股财年 1-1 至 12-31），不混用 FY。
- 季度记 `25Q1`/`25Q4`/`26Q1`。报告日 `YYYY-MM-DD`。T-0 = 报告当日收盘。
- 股价历史一律**前复权（qfq）**。

## 表格
- 表头加粗，数字列右对齐。缺失值用 `—` 或"未取得"，不用 `N/A`/`null`/空白。

## 语气（判断稿的核心，与数据稿相反）
- **第一人称、有立场、敢写减分项。** "我认为""我判断""我都不明白""我就不敢猜了"都合适。
- **避免无责任措辞**："或将""有望""值得期待"看似严谨、实则不担判断。宁可"我认为大概率持续，因为……"，不写"有望持续"。
- 不给买入/卖出评级、不给股价目标位——出口是市值区间 + 赔率 + 五维字母评级 + 一个决定性变量。
- 不用 emoji。不用 `[H/M/L]` 逐句置信度标记（那是数据稿的做法）。

## 章节小标题
- 一级 `## 一、xxx`；二级 `### 1.1 xxx`；三级 `**Xxx**`（加粗，不用 `####`）。

## 免责声明（报告末尾固定）
> 本报告为判断型研究稿，含大量主观判断与自建假设，数据来自公开源及人工注入的一手信息。**不构成投资建议**。
