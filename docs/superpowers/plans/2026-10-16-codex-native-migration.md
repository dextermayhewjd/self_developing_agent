# Codex 原生迁移实施计划

设计：[原生迁移](../specs/2026-10-16-codex-native-migration-design.md)。用户已选择保留确定性编排器，使用并行实施及独立审查。

1. 记录缺失能力基线和现有测试基线；保护未提交改动。
2. 迁移六个技能与全部研究资料到 `.codex/skills`，接入 `.agents` 发现。翻译平台指令，拆出成稿契约；记录源文件快照及明确差异。
3. 迁移三条工作流与执行器路径、指纹、恢复测试，保持股票流程事务和独立审查。
4. 完成校准的持久化、完整证据复用、对撞、抽查与报告/改写稿交付；加入有意义的失败与阈值测试。
5. 新增 Codex 日志审计，迁移调试技能；移除同业池隐藏 Claude 路径依赖。
6. 更新操作说明和迁移对照。运行无 Claude 隔离验收、技能验证、全量回归和独立审查，修正发现。

## 重点验证

- 本地资源、数据准备或指纹仍读 `.claude`。
- 成稿重新加载冲突的旧调度步骤。
- 校准只得到中间 JSON 就被认定完成，或缺证据时错误复用。
- 修改提案越过支持度/原文抽查门槛，或直接修改方法。
- 审计把缺少日志当成无越界，或把普通读文件一律判为违例。
- 链接可发现但引用失效；旧运行被静默覆盖。
