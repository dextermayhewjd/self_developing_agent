# 中金行业体系 · 指标库分类树（参照快照）

> **这是第三方（中金点睛）的产品分类结构，不是本仓的设计。**
>
> - 来源：`research.cicc.com/data/ind/rrp/indicator-directories?parentId={id}`，需订阅账号登录
> - 爬取日：2026-08-27，深度至第 4 层
> - 用途：**设计参照与校验**——用它检验我们自己提取的品种/环节切法对不对，
>   而不是直接把它当配置用。
> - **禁止**：不得整树搬进 `valuation_archetypes.md` 等本仓配置；
>   不得出现在任何对外产物（判断稿、台账）里；不得再分发。
> - 机器可读版：同目录 `.json`（含节点 id，便于日后重爬比对）
>
> ## 为什么留它
>
> 2026-08-27 为「可比性台账」项目找现成行业框架时爬的。**结论是它不能直接用**
> （见 `docs/superpowers/specs/2026-08-27-peer-comparability-design.md` 第八点五节），
> 但留档有两个用处：一是日后想再借外部框架时，不必重走一遍这条路；
> 二是它可以当作我们自建品种表的**对照组**——我们提出来的品种切法与它差多少，
> 是一个可量化的检验。
